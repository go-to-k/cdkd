# Key Files and Directories - scripts and docs/_generated

Every area: [code-layout.md](code-layout.md).

## Important Files

- **scripts/gen-enrichment-coverage.ts** + **docs/_generated/enrichment-coverage.{json,md}** - CC-API enrichment-coverage matrix + critic (`gen:enrichment-coverage` / `audit:enrichment-coverage:check`). BLOCKS only on `unenriched-computed`, a gap on a pure-CC type; a readOnly prop that IS the `primaryIdentifier` is not one.

- **scripts/gen-sdk-attr-coverage.ts** + **docs/_generated/sdk-attr-coverage.{json,md}** - SDK-provider ARN/URL attribute-coverage matrix + critic (`gen:sdk-attr-coverage` / `audit:sdk-attr-coverage:check`) for the GetAtt-key class, an ARN recorded under a non-CFn key. Detail: [sdk-attr-coverage-critic.md](sdk-attr-coverage-critic.md).

- **scripts/gen-update-wrap-coverage.ts** + **docs/_generated/update-wrap-coverage.{json,md}** - SDK-provider `update()` error-wrapping matrix + critic (`gen:update-wrap-coverage` / `audit:update-wrap-coverage:check`), BLOCKING on `gap` and `unguarded-wrap`. A wrapping `catch` that can capture a control-flow typed error MUST re-throw the CAUGHT BINDING; throwing anything else is the defect.

- **scripts/gen-nested-key-coverage.ts** + **docs/_generated/nested-key-coverage.{json,md}** - Nested CFn -> SDK key-divergence matrix + critic (`gen:nested-key-coverage` / `audit:nested-key-coverage:check`), the only guard on the nested write-side silent-drop class. BLOCKS on `case-divergence`, `no-sdk-member`, `no-write-evidence`, `array-vs-wrapper`, `definition-member-missing`. In the WRITE-EVIDENCE pass a `same-spelling` key must ALSO appear as a WRITTEN SDK member; a READ does not count, which scopes evidence to the CFn -> SDK direction.

- **scripts/gen-handled-property-wiring.ts** + **docs/_generated/handled-property-wiring.{json,md}** - `handledProperties` WIRING matrix + critic (`gen:handled-property-wiring` / `audit:handled-property-wiring:check`): no sibling checks that a declared property is WIRED to an API call. Evidence is CLASS-SCOPED via a taint walk from each method's desired-state parameter, passed on only through calls taking the bag WHOLE; a read of `previousProperties` is NOT evidence, since diff-only proves DETECTION, not delivery.

- **scripts/audit-stateful-candidates.ts** + **docs/_generated/stateful-candidates.{json,md}** - Tier-2 stateful-candidate derivation, a THIRD lower bound on `STATEFUL_TYPES` (issue [#2553](https://github.com/go-to-k/cdkd/issues/2553)); `:regenerate` calls AWS, `:check` is the offline critic. The other two bounds derive from `providers/**` and so are blind to tier 2. It PROPOSES a type whose schema declares a `createOnlyProperties` entry AND fires a data-bearing signal; one in NEITHER the candidate list nor the `NOT_GUARDED` write-off map FAILS `--check`.

- **scripts/check-integ-capture-shape.ts** - Abort-shaped capture fence for `tests/integration/*/verify.sh` (issue [#3126](https://github.com/go-to-k/cdkd/issues/3126)); the unit test `integ-verify-capture-shape.test.ts` IS the enforcement. Under `pipefail`, `V=$(cmd 2>/dev/null | tail -1)` aborts at the assignment with stderr already discarded; the rule and the correct `capture` form are in [abort-capture.md](abort-capture.md). It also BLOCKS a `verify.sh` not setting pipefail, the shape being undefined without it.

- **scripts/check-source-control-bytes.ts** - Stray-control-byte working-tree sweep; `source-control-bytes.test.ts` IS the enforcement. A raw NUL is valid in a string literal and runtime-identical, so every gate passes, but `grep` / `rg` classify the whole FILE as BINARY and silently skip it at exit 0 while `git grep` is UNAFFECTED. It rejects every C0 byte plus DEL except TAB / LF.

- **scripts/check-docs-error-strings.ts** - Quoted-error fence for `docs/**` (issue [#2757](https://github.com/go-to-k/cdkd/issues/2757)), enforced by `docs-error-strings.test.ts`. A fenced `SomeError: some text` line must satisfy two decidable halves: `SomeError` is a name cdkd assigns, and the message instantiates a real TEMPLATE. **A truncated quotation (`...`) is REFUSED** before the match, since a trailing hole absorbs the dots.

- **scripts/check-provider-error-cause.ts** - Cause-threading critic for provider `catch` sites (issue [#2040](https://github.com/go-to-k/cdkd/issues/2040)), run by `vp run audit:provider-error-cause:check`. cdkd's three transient-error classifiers walk the error's `.cause` chain, so a provider wrapping an AWS failure WITHOUT threading the caught value makes all three INERT for that call. Threading is checked STRUCTURALLY, not by identifier name. Scope: `src/provisioning/providers` only (issue [#2075](https://github.com/go-to-k/cdkd/issues/2075)).

- **scripts/check-provider-secret-mask.ts** - Pre-stringify secret-mask critic for provider message sites (issue [#2178](https://github.com/go-to-k/cdkd/issues/2178)), run by `vp run audit:provider-secret-mask:check`. [provider-masking.md](provider-masking.md) requires a `properties`-derived value interpolated into a message to be masked BEFORE `JSON.stringify`, which escapes `"` / `\` / newlines so the finished message cannot be recovered.
  - The masker set is DERIVED then grown to a FIXPOINT. **An IDENTITY masker is REFUSED in BOTH positions** — the derivation ROOT and the shared walk's MASKER ARGUMENT, where a root-only refusal is inert; that argument is an ALLOW-LIST, not a deny-list, the set of no-op spellings being unbounded. **BOUND**: a no-op DECLARED to be the capability is still believed, so state the fence as "the value reached something DECLARED to be the project's masker". It checks SHAPE, so it needs the RUNTIME twin `<provider>-masked-warn.test.ts`, whose secret contains a quote and a newline: a plain alphanumeric one passes even with masking AFTER the stringify.

- **scripts/check-withretry-interrupt.ts** - Interrupt-threading critic for `withRetry` call sites under `src/provisioning/**` (issue [#2053](https://github.com/go-to-k/cdkd/issues/2053)), run by `vp run audit:withretry-interrupt:check`. `withRetry` is the ONLY cdkd wait that consults an interrupt DURING a backoff, so a call omitting `isInterrupted` / `onInterrupted` leaves Ctrl-C dead for its whole schedule. It requires BOTH names as DIRECT properties of an options OBJECT LITERAL: half a pair is a defect, and a conditional spread does not count, since it reads as threading while absent whenever its guard is falsy.

- **scripts/check-aws-client-defaults.ts** + **tests/aws-client-defaults-allowlist.json** - AWS SDK client construction critic (`vp run audit:aws-client-defaults:check`). Documented with the modules it fences: [proxy-support.md](proxy-support.md).

- **scripts/check-local-reachability.ts** - Symbol-level reachability critic for `src/local/**` (issue [#2228](https://github.com/go-to-k/cdkd/issues/2228)), via `vp run audit:local-reachability:check`. Every exported VALUE symbol with a cdkd-authored body must be transitively reachable from a shipped entry point (`pack.entry` in `vite.config.ts`) or carry `@no-live-caller` / `@test-only-export` at its declaration. SYMBOL-level, not module-level: a module can HAVE a live importer while everything it exports is called only from never-called functions. Reachability is an OVER-APPROXIMATION biased toward LIVE: a clean run is not proof a symbol executes.

- **scripts/check-provider-update-context.ts** - SDK-provider `UpdateContext` declaration fence (issue [#2613](https://github.com/go-to-k/cdkd/issues/2613)); `provider-update-context.test.ts` enforces it. `ResourceProvider.update`'s `context` is OPTIONAL, so a provider omitting it compiles while `assertRegionMatch` — the UPDATE twin of the DELETE-path guard — never runs for it. Nothing reds, so `OMITS_UPDATE_CONTEXT` records the omitting set BY NAME.
  - The unit is the CLASS, not the file, and membership is `create` + `update` + `delete` being present, not the OPTIONAL `implements ResourceProvider` keyword or `async`. Declaring is STRUCTURAL; every other shape is REFUSED, not bucketed: the 6th parameter must be a plain identifier annotated `UpdateContext`, bound by an import resolving to [src/types/resource.ts](../../src/types/resource.ts), matched INCLUDING the separator before `types`. A provider inheriting `update` from a base is IGNORED by the scan; the RUNTIME half covers it, since every registered provider's `update.length` must agree.

- **scripts/refresh-cfn-schemas.mjs** and the refresh chain around it — `scripts/diagnose-schema-refresh.mjs`, `scripts/sync-backfill-umbrella.ts`, `scripts/offline-property-evidence.ts`, `scripts/published-sdk-typings.ts`, and `.github/workflows/{cfn-schema-refresh,backfill-umbrella-sync}.yml`. It PRODUCES `tests/fixtures/cfn-schemas/*.json`, the offline oracle every coverage critic and the deploy-time SDK-vs-Cloud-Control routing table are derived from. Full entries — the two capture sources and one fixture shape, the collapse floors, the offline removal classifier, the decision hand-off, and the backfill campaign's generated umbrella checklist — in [layout-schema-refresh.md](layout-schema-refresh.md), whose `paths:` glob is narrow enough that this detail is a token toll only on a session actually touching them.

- **The CI checks that replaced PreToolUse gates** — `scripts/check-pr-title-prefix-scope.ts`, `check-pr-non-english-text.ts` (+ `scripts/non-english-allowlist.txt`), `check-pr-internal-labels.ts`, `check-pr-closes-paren.ts`, `check-gh-body-english.ts`, `check-issue-classification-labels.ts`, `check-issue-dup-check.ts` and the shared `scripts/gh-subject.ts`, run from `.github/workflows/{pr-title-check,pr-content-checks,issue-conventions}.yml`. Their subject is a GitHub artifact, not `src/`: no `audit:*` task, no `docs/_generated` output. Full entries: [layout-ci-checks.md](layout-ci-checks.md).

# cdkd import / cdkd export

Rest of the CLI: [layout-cli.md](layout-cli.md). Index: [code-layout.md](code-layout.md). Per-type `provider.import` coverage is single-sourced in [docs/import.md](../../docs/import.md).

## `cdkd import`

- **Module layout.** `import.ts` holds `createImportCommand` and re-exports all public symbols; code lives in `import/*.ts`, `command.ts` (`importCommand` up to the lock) and `locked-import.ts` (`runLockedImport`, the lock-held body) among them. Source fences read the set via `tests/unit/cli/_import-source.ts`.
- **Three modes.** AUTO (no flags) resolves each resource from its physical-name property, then a same-named CloudFormation stack. SELECTIVE, the default whenever a `--resource` / `--resource-mapping` flag is given, imports only listed resources and marks the rest `out of scope`. HYBRID is `--auto` plus overrides.
- **There is deliberately NO `aws:cdk:path` tag lookup**: AWS reserves the `aws:` prefix, so that tag can never exist. The CloudFormation fallback is best-effort, flat, and skipped in selective mode.
- **`--force` is not upstream's**: required only where the import would LOSE data (an auto rebuild over state, a selective override of a recorded resource); selective mode otherwise merges.
- **Per-resource SDK calls, not a changeset, so import is NOT atomic.** State is written only after a final confirmation, and a partial import is backed out with `cdkd state orphan`.
- **The `attributes` bag is redacted by `resolveImportedProperties`, ABOVE the observed-baseline refusal, and never DROPS a key** ([#2847](https://github.com/go-to-k/cdkd/issues/2847)).
- **src/cli/commands/import-deployed-parameters.ts** — ARM 4 of the observed-baseline refusal ([#2854](https://github.com/go-to-k/cdkd/issues/2854)): the `DescribeStacks` parameter read, and the provable-equality comparison; the parameter-dependence walk is `src/analyzer/parameter-dependence.ts`, shared with `cdkd deploy`. Deployed values are COMPARISON-ONLY — never bound into the resolve, logged, or persisted (a nested child's `DescribeStacks` can answer a decrypted value). `resolveImportedProperties` returns an `ObservedBaselineRefusals` set carrying which ids ARM 4 named and whether the run had a deployed-parameter source; the capture writes, keeps or clears `observedBaselineRefusalReason` from those two facts ([state-schema.md](state-schema.md)).
- **`--migrate-from-cloudformation [name]`** (cdkd-specific, defaulting to the cdkd stack name):
  - BEFORE the import loop one `DescribeStackResources` merges into the overrides, user entries winning; it then forces `selectiveMode = false` whatever the override count, or every other resource is orphaned by the later `DeleteStack`.
  - State `properties` come from CloudFormation's DEPLOYED template (`deployed-properties.ts`, #6840), nested children too; one it cannot resolve keeps the synthesized ones, WARNED.
  - Records merge stack tags (#6887): the root CFn stack's (`readDeployedStackTags`), a child its parent's plus the deployed row's LITERAL `Tags` (never resolved values: secrets); others `StackInfo.tags`.
  - The Retain `UpdateStack` (both policies) runs BEFORE the state write; it can REPLACE a resource, so state takes the re-read ids ([#4873](https://github.com/go-to-k/cdkd/issues/4873)); `DeleteStack` after, in the lock. No `--dry-run`.
  - Nested stacks are RECURSIVE ([#464](https://github.com/go-to-k/cdkd/issues/464)): one v6-keyed child state file carrying `parentStack` / `parentLogicalId` / `parentRegion`, `Retain` on every leaf of both templates, one parent-side `DeleteStack` cascade. The parent's nested row records the SYNTHESIZED cdkd-local ARN, not the real child stack ARN.

## `cdkd export`

- **Module layout.** `export.ts` holds `createExportCommand` and re-exports all public symbols; code lives in `export/*.ts`: `command.ts` (`exportCommand`), `command-helpers.ts`, `plan-types.ts`, `render.ts`, `stack-tree.ts`, `import-plan.ts`, `type-schema.ts` (`DescribeType`), `composite-id-splitters.ts` + `composite-id-shapes.ts`, `composite-physical-id.ts`, `sg-ingress-rule-id.ts`, `pre-delete.ts`, `parameters.ts`, `ssm-parameter-preflight.ts`, `template-overlay.ts`, `drift-baseline.ts`, `changeset.ts`, `exported-stack-tags.ts`, and `per-stack-loop.ts` + `per-stack-phases.ts` (nested pre-flight, per-stack IMPORT phases). Source fences read the set via `tests/unit/cli/_export-source.ts`.
- **Stack tags** (#6887): an IMPORT creating a stack REFUSES `Tags`, so the root's go on by a tag-only `UpdateStack` that only WARNS; that update REPLACES the set, so each flip carries the child's tags.
- Ends in an IMPORT changeset and DELETES cdkd state, all-or-nothing; `buildImportPlan`, its `blocked` hard-fail and the SSM check run BEFORE `acquireLock`.
- **Blocked**: properties holding the mask `***` OUTSIDE the record's `noEchoLeaves` (a `NoEcho` position is let through, unless the IAM policy pre-delete reads it); a nested child parameter resolving to the mask (refused, never defaulted); a RESOLVED import identifier that would be, or embeds, the mask, checked at the identifier choke point and NOT as a whole-bag `attributes` test (`CloudControlProvider.import` masks writable keys by design); a never-importable type (`Custom::*`, `AWS::CloudFormation::CustomResource`); a resource absent from state ([#2274](https://github.com/go-to-k/cdkd/issues/2274)).
- Identifiers come from `DescribeType`, then a hand table or snapshot. A `COMPOSITE_PHYSICAL_ID_IDENTIFIERS` type resolves from state `attributes` BEFORE the field-count branch with an EMPTY `propertiesOverlay`, an unrecorded value BLOCKING; `COMPOSITE_ID_SPLITTERS` entries shape-bind BOTH segments; a live backfill must match EXACTLY ONCE ([#1659](https://github.com/go-to-k/cdkd/issues/1659)).
- The import-support pre-flight blocks every offender in one pass, but its verdict needs TWO agreeing fields (no `read` handler AND `NON_PROVISIONABLE`), so a partial response resolves `unknown` and defers to AWS. It runs AFTER the `IMPORT_UNSUPPORTED_RECREATABLE_TYPES` branch, and `--skip-import-support-preflight` bypasses it. **A read handler is necessary but not sufficient**: `CFN_IMPORT_REFUSED_DESPITE_REGISTRY` (dated, MEASURED) blocks a type CloudFormation refuses for IMPORT despite the registry ([#3414](https://github.com/go-to-k/cdkd/issues/3414): `AWS::AppSync::GraphQLApi`). `PHYSICAL_ID_NOT_IMPORT_IDENTIFIER` (checked first, NOT bypassed by the flag) blocks a type cdkd records no identifier value for (#4668); one with a recorded value belongs in `COMPOSITE_PHYSICAL_ID_IDENTIFIERS`.
- `AWS::AppSync::GraphQLApi` is the one `COMPOSITE_PHYSICAL_ID_IDENTIFIERS` member whose cdkd physicalId is NOT composite: AWS moved the identifier from `ApiId` to `Arn`, cdkd stores the bare `apiId`, and the entry resolves from the recorded `Arn` attribute. Its `physicalIdIsIdentifierFor: ['ApiId']` sends a registry still answering the OLD field down the single-key path, an ARN-shaped physicalId excluded. `AWS::AppSync::ApiKey` sits in `COMPOSITE_ID_SPLITTERS` and decodes THREE shapes (cdkd's `<apiId>|<apiKeyId>`, the key ARN a pre-#5364 migration recorded, and a bare `<apiKeyId>` from a pre-flip Cloud Control record, taking `ApiId` from properties).
- `overlayResourceIdentifierOnProperties` classifies the template's current value ([#1787](https://github.com/go-to-k/cdkd/issues/1787)): an ABSENT key and a top-level INTRINSIC are LEFT ALONE; any LITERAL is OVERWRITTEN, the recorded physicalId being the authority; a list is REFUSED.
- Nested export submits **one IMPORT changeset per cdkd stack, leaf-first**, while parameter resolution is a ROOT-FIRST pre-pass through the deploy engine's resolver. A parent adopts its child with `Retain` + `ResourceIdentifier: { StackId }` + a post-IMPORT `TemplateURL` ([design](../../docs/design/464-nested-stacks-export-import.md)).
- **Context guard**: refuses `-c` overrides (not persisted); `--accept-transient-context` opts in.
- Both commands keep their OWN nested-template indexer, and each runs `resolveAssemblyPath` ([layout-utils.md](layout-utils.md), [#3489](https://github.com/go-to-k/cdkd/issues/3489)) beside its absolute-path tripwire, against the PARENT TEMPLATE's directory. An escaping row is as load-bearing here as on deploy; the two refusals stay worded apart. Each indexer — and each `??` fallback for a stack with no indexable row — builds onto `nullPrototypeRecord()`, never a `{}` literal, and `defineOwnKey` is NOT a substitute: both files test membership with `if (!index[id])`, which on a plain object answers an inherited `Object.prototype` member ([own-keys.md](own-keys.md), [#3480](https://github.com/go-to-k/cdkd/issues/3480)).
- **src/cli/yaml-cfn.ts** - CFn-aware YAML codec: shorthand tags parse to their long form (ONE representation) and re-emit as shorthand.

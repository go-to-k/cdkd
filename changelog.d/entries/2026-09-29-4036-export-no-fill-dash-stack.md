- **`cdkd export`'s unreadable-entry warning no longer tells the operator to fill a `-`-leading stack name back into `cdkd state show`** (`src/cli/commands/export.ts` `reportDriftBaselineGaps`, go-to-k/cdkd#4036). When the command it prints carried a quoted `'<stack>'` hole, the sentence before it said to fill the hole from `cdkd state list --json` whatever the name was, so a record named `--all` or `--state-bucket=x` led to a pasted command whose positional Commander parsed as an option. A stack name beginning with `-`, keyed on the raw `-` as `inspectClause` is (go-to-k/cdkd#4011), now gets a sentence saying not to fill the stack hole with it and to repair or remove the record by hand; a withheld region beside an ordinary name keeps the fill-in. Tests: `tests/unit/cli/export.test.ts`.

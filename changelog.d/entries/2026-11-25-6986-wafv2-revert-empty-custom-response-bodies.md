- **`cdkd drift --revert`: a WAFv2 web ACL without custom response bodies can be reverted (issue [#6986](https://github.com/go-to-k/cdkd/issues/6986))** -- `src/provisioning/providers/wafv2/shared.ts`, `src/provisioning/providers/wafv2/update.ts`, `src/provisioning/providers/wafv2/create.ts`. The deploy records a web ACL with no `CustomResponseBodies` as `{}`, and `--revert` builds its request from that record. `UpdateWebACL` refuses an empty map (`Member must have length greater than or equal to 1`), so every revert of a web ACL whose template declares no custom response bodies failed with `ValidationException` and exit `2`, and the drifted rules or default action stayed as changed. cdkd now omits an empty map from `UpdateWebACL` and `CreateWebACL`, which both read as "no custom response bodies". A declared map is sent as before. Tests: `tests/unit/provisioning/wafv2-provider-roundtrip.test.ts`; integ `wafv2` phase 3b.

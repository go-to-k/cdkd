- **`Ref` on four types now returns the value CloudFormation returns (issue [#6243](https://github.com/go-to-k/cdkd/issues/6243))** -- `src/deployment/intrinsic-resolver/ref-values.ts`, unit tests and a new `ref-shape-vector-namespace-attachment` integ fixture. `AWS::S3Vectors::VectorBucket` and `AWS::AppSync::GraphQLApi` resolved to the bucket name / API id instead of the ARN, `AWS::S3Tables::Namespace` to the bare namespace name instead of `<tableBucketARN>|<namespace>`, and `AWS::EC2::VPCGatewayAttachment` to `<gatewayId>|<vpcId>` instead of `IGW|<vpcId>` / `VGW|<vpcId>`, each with no warning. A template wiring one of these `Ref`s into an IAM policy, an output or a sibling property got a value CloudFormation never returns. Each value was measured against a real CloudFormation deploy of the same template.

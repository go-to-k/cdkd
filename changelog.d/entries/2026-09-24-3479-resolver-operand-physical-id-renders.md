- **Resolver and template-parser log lines no longer print an `Fn::Select` index, an `Fn::Split` delimiter, a state-record physical ID or a template logical ID raw (issue [#3479](https://github.com/go-to-k/cdkd/issues/3479), partial)** -- `src/deployment/intrinsic-function-resolver.ts`, `src/analyzer/template-parser.ts`. These values could carry terminal control characters, line terminators or bidi overrides, and several lines printed them as written: the `Fn::Select` out-of-bounds warning and its debug line, the `Fn::Split` debug line, the VPC `Ipv6CidrBlocks` lines, the ServiceDiscovery `HostedZoneId` and `DescribeLaunchTemplates` failure warnings (including the AWS error text, which echoes the ID), and the template validator's `Resource <id> is not an object` / `missing Type` errors plus its condition-exclusion debug line. Each now renders through the display sanitizer, which maps those characters to spaces. An ordinary value prints exactly as before. Tests: `tests/unit/deployment/resolver-operand-physical-id-control-chars.test.ts`, `tests/unit/analyzer/template-parser-control-chars.test.ts`.

- **`cdkd events`, `cdkd diff`, `cdkd drift` and `cdkd list` `--json` output no longer carries terminal-active characters raw** (`src/cli/commands/{events,diff,drift,list}.ts`, go-to-k/cdkd#4045). These payloads called `JSON.stringify` directly, which escapes only C0, `"`, `\` and lone surrogates, so a stored event `reason`, run field, state property value, drift value or stack name reached the terminal with DEL, the C1 range (`U+009B` is a live CSI), `U+2028` / `U+2029`, the bidi controls and the zero-width characters verbatim. They now go through `stringifyJsonPayload`, like `cdkd state` since go-to-k/cdkd#3163: every control, format, line-separator and paragraph-separator character is written as a `\uXXXX` escape, the output parses back to exactly the same values, and a plain payload is byte-identical. `cdkd list --json` values are still passed through the display sanitiser first, so that payload is escaped but not lossless (go-to-k/cdkd#3479); its YAML mode is unchanged. Tests: `tests/unit/cli/{events-json-stream,drift-json-stream,list-display-safe,diff-json-escape}.test.ts`.

- **`cdkd drift` no longer drops a user's key named like an AWS-managed field inside a free-form map (issue [#6854](https://github.com/go-to-k/cdkd/issues/6854))** -- `src/analyzer/cc-api-strip.ts`, `tests/unit/analyzer/cc-api-strip.test.ts`. A Cloud Control fallback read (`AWS::AppConfig::Environment`, a nested `AWS::CloudFormation::Stack`) dropped keys such as `CreatedBy` or `OwnerId` wherever they appeared, including a user's own tag or stack parameter of that name, so drift reported the key removed. Keys at or below a user-keyed map (`Tags`, `Parameters`, `Variables`, `DockerLabels`, ...) are now kept.

- **`cdkd local start-service` / `start-alb` ECS containers and `cdkd local` Lambda containers now get the region cdkd resolved, and `local start-api` serves a REST API integration with `ResponseTransferMode: STREAM` through response streaming (issue [#6210](https://github.com/go-to-k/cdkd/issues/6210))** -- `package.json` (`cdk-local` `^0.165.0` -> `^0.165.1`). Before this change, an ECS service container in an environment-agnostic stack saw no `AWS_REGION` / `AWS_DEFAULT_REGION` unless the shell exported one, a Lambda container's region ignored the profile / state region on one of the two credential paths, and a `STREAM` integration was served buffered. Now the container gets the resolved region (an `AWS_REGION` in the shell ranks above `--stack-region`), and a `STREAM` route is streamed chunk by chunk.

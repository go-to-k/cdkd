- **`cdkd deploy` no longer persists a legacy nested row's secret-derived output in plaintext (issue [#7097](https://github.com/go-to-k/cdkd/issues/7097))** -- `src/deployment/legacy-row-output-mask.ts`, `src/cli/commands/diff-recursive/deleted-subtree-taint.ts`. A nested-stack row passing a parameter that mixes a secret reference with other text (#7068's shape), recorded before cdkd masked a secret-derived nested output, held that output's plaintext. A deploy over it wrote the plaintext into the producer's outputs, its export and the exports index, and every importing stack's deploy plan and `--require-approval` summary printed it. Such a record now reads as a current one: each output the child template derives from the mixed parameter reads `***`, so the output and its export persist `***` and a property reading it is refused, as on a current record. Outputs reading nothing mixed keep their values. When the child template cannot be read to decide, the deploy is refused, naming the row and the output and how to re-record them. `cdkd diff --recursive` also masks the values of a deleted nested row's subtree when the row's recorded parameters carry such a value.

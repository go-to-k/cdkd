- **Removing a dead-letter queue from an SNS subscription no longer fails the deploy (issue [#6835](https://github.com/go-to-k/cdkd/issues/6835))** -- `src/provisioning/providers/sns-subscription/attribute-plan.ts`, `src/provisioning/providers/sns-subscription-provider.ts`, `tests/unit/provisioning/sns-subscription-in-place-update-4853.test.ts`. Dropping `deadLetterQueue` from an `SqsSubscription` / `LambdaSubscription` (a `RedrivePolicy` removed from an `AWS::SNS::Subscription`) sent `SetSubscriptionAttributes` with an empty value, which SNS refuses ("RedrivePolicy: missing required value"), so the deploy failed and rolled back. cdkd now clears it with the value omitted, the call SNS accepts, keeping the subscription in place as CloudFormation does. A rollback or `cdkd drift --revert` that clears a dead-letter queue takes the same path.

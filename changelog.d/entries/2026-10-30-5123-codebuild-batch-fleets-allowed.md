- **`AWS::CodeBuild::Project` sends `BuildBatchConfig.Restrictions.FleetsAllowed` (PR [#5123](https://github.com/go-to-k/cdkd/pull/5123))** -- `src/provisioning/providers/codebuild-provider.ts`. Before this change, the SDK provider forwarded only `MaximumBuildsAllowed` and `ComputeTypesAllowed` from a batch build's `Restrictions`, so a declared `FleetsAllowed` list never reached CodeBuild and batch builds were not limited to those fleets. The project readback now reports the list too, so `cdkd drift` compares it.

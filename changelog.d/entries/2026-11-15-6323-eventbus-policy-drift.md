- **`cdkd drift` no longer reports an event bus `Policy` written by an `AWS::Events::EventBusPolicy`, and `--revert` no longer writes a stale policy back (issue [#6323](https://github.com/go-to-k/cdkd/issues/6323))** -- `src/cli/commands/drift/baseline-keys.ts`. When a deploy changed both the bus and its `EventBusPolicy` statement, the bus's recorded baseline kept the old statement, so drift reported the live policy as drift and `drift --revert` re-applied the old document, dropping the newer statement (for example, a `Condition` that narrowed access). Drift now compares an event bus's `Policy` only when the template declares it on the bus, as CloudFormation does. Existing stacks are fixed without a redeploy.

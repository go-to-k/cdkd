- **`AWS::ElasticLoadBalancingV2::TargetGroup` `Targets[].QuicServerId` now reaches ELBv2 (issue [#5394](https://github.com/go-to-k/cdkd/issues/5394))** -- `src/provisioning/providers/elbv2-provider.ts`. The member was dropped when targets were converted, and the update diff did not key on it, so it was never sent on `RegisterTargets` / `DeregisterTargets` and a change to it alone was never applied. It is now sent on create and update and echoed from the `DescribeTargetHealth` readback (so `cdkd drift --revert` does not deregister a live QUIC target). A change to the server id alone deregisters the old target before registering the new one, as AWS requires; an empty, non-string or secret-derived value is refused before any call.

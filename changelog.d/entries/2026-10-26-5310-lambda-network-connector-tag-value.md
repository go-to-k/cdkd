- **A `AWS::Lambda::NetworkConnector` tag without a `Value` is no longer refused (issue [#5310](https://github.com/go-to-k/cdkd/issues/5310)).** The CloudFormation schema requires only `Key` on a tag of this type, so a `{ Key }` entry deploys on CloudFormation, but cdkd refused it as "not a list of tags with a scalar Value" before any write. Create and update now accept an entry without a `Value` and tag it with an empty value, as the RDS DBProxy providers already do; an entry without a `Key` is still refused.

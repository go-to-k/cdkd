- **Resolver refusal messages mask a 1-3 character piece of a secret-carrying operand (issue [#7105](https://github.com/go-to-k/cdkd/issues/7105))** -- `src/deployment/intrinsic-resolver/**`. The `Fn::Select`, `Fn::Split`, `Fn::GetStackOutput`, `Fn::GetAtt`, `Fn::Sub`, `Fn::Cidr`, Secrets Manager and SSM refusals rendered a resolved operand with the value scan alone, so a piece of a parameter mixing a secret reference (#7077's shape) printed in the error at default verbosity, as in `Fn::Select: the index (string "q7") must resolve to a non-negative integer`. They now render it through `logOperand`, as the `--verbose` lines do since #7077. `resolver-log-operand-population.test.ts` reads every `new <X>Error(...)` message in the resolver too.

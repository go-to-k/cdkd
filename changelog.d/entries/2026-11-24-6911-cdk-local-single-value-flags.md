- **`cdkd local start-alb` / `start-service` / `run-task` keep a target written after a repeatable flag, so `cdkd local start-alb --lb-port 80=8080 MyStack/Alb` starts `MyStack/Alb` (issue [#6911](https://github.com/go-to-k/cdkd/issues/6911))** -- `package.json` (cdk-local `^0.169.3`), `tests/unit/cli/local-start-alb.test.ts`, `docs/local-start-alb.md`, `docs/local-start-service.md`, `docs/local-run-task.md`. `--lb-port`, `--host-port`, `--image-override`, `--image-build-arg`, `--image-build-secret`, `--image-target` and `--image-context` come from cdk-local, which declared them variadic, so a target after one of them was consumed as a value. cdk-local 0.169.3 (go-to-k/cdk-local#1021) takes one value per flag, matching cdkd's own `-c` / `--tags`. Repeat the flag for several values (`--lb-port 80=8080 --lb-port 443=8443`); `--lb-port 80=8080 443=8443` now reads `443=8443` as a target.

- **A `NoEcho` template parameter's value no longer prints in `cdkd deploy --verbose`'s `requires replacement (<old> -> <new>)` line or in the export-alias warnings (issue [#4049](https://github.com/go-to-k/cdkd/issues/4049))** -- `src/analyzer/diff-calculator.ts`, `src/deployment/deploy-engine.ts`, `src/deployment/outputs-export-alias.ts`, `src/deployment/secret-redaction.ts` (`printingCorpusOf`, `recordLogOnlyParameterValue`, `createUnionSecretMasker`), `src/deployment/intrinsic-function-resolver.ts`, `src/cli/commands/scrub.ts`, and unit cases. Before, the deploy's diff resolved a `Ref` to a `NoEcho` parameter to its plaintext and printed it on the replacement line of a create-only property, and an `Export.Name` built from one printed it in the collision warning. The diff calculator now takes a printing masker over the diff pass's own bag, every `NoEcho` parameter's value and a nested child's inherited bag, masks each value before stringifying it, and withholds the old side as `***` when the new side carries a masked value, because the old value in state is usually the previous one, which is no needle. The export-alias collision, secret-bearing and `cdkd scrub` collision warnings, and `cdkd scrub`'s export-index repair lines, mask the log-only needles too. An output resolution failure, and the resolver's log lines and thrown errors, are masked with their bags in one pass, so a shorter value can no longer split a longer one. Nothing persisted or published changes: `state.json` is byte-identical with or without `NoEcho`, and whether an `Export.Name` embedding the value is published is still decided from the recorded secrets alone ([#4043](https://github.com/go-to-k/cdkd/issues/4043)). `cdkd diff`'s own rendering and the Outputs summary remain on #4049.

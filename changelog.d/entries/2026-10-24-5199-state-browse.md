- **`cdkd state browse`: pick a stack with the keyboard and view its resources or record (issue [#5199](https://github.com/go-to-k/cdkd/issues/5199))** -- `src/cli/commands/state-browse.ts` and `src/cli/interactive-select.ts` (new), `src/cli/commands/state.ts` (`printStackResources` / `printStackShow`, the bodies of `state resources` / `state show`, now shared), `docs/cli-state.md`, new unit files. Lists the stacks in the state bucket; arrow keys move, typing filters, Enter picks. A picked stack offers its resources, its resources with dependencies and attributes, and its full record, each printed by the same code as `cdkd state resources`, `cdkd state resources --long` and `cdkd state show`. Without a terminal it exits 1 before any AWS call.

- **A pasteable `aws ...` command no longer names a value the AWS CLI itself acts on (issue [#4199](https://github.com/go-to-k/cdkd/issues/4199))** -- `src/provisioning/replacement-protection-advice.ts`, `src/provisioning/providers/{scheduler-schedule,ec2,eventbridge-rule}-provider.ts`. The gate that provider messages route a pasteable `aws` command's template- or state-borne values through (`renderDisableCommand` and the `pasteableAwsCommand` tag) admitted a value starting with `file://` / `fileb://`, which the AWS CLI replaces with a LOCAL file's contents (so a pasted command could send, e.g., the operator's credentials file to AWS), `http://` / `https://`, which aws-cli v1 fetches, a shorthand `@=` (`Key@=file://path`, the same file load mid-word), and a leading `-`, which after a list-valued flag parses as an option such as `--endpoint-url`. Such a value is now withheld and the message points to the console; the scheduler's hand-built delete hint applies the same check (`AWS_CLI_ACTIVE_ARG` / `isAwsCliLiteral`). The EC2 `--no-wait` re-associate hint also withholds an instance profile holding `,`, which inside `Arn=<value>` shorthand starts another key. The EventBridge partial-create cleanup hint passes the listed target ids to `--ids` as one JSON word instead of through `jq | xargs`, where a target id starting with `-` became an option (`--region`, `--profile`), and says that a `remove-targets` error on a rule with no targets left is harmless. Tests: `tests/unit/provisioning/pasteable-aws-cli-active-arg.test.ts`, `ec2-instance-no-wait-gate.test.ts`, `eventbridge-rule-provider-partial-create-cleanup.test.ts`.

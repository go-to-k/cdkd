- **A rollback masks a secret-derived name wherever an ARN or a Cloud Control composite id keeps it, not only in its last segment (issue [#4138](https://github.com/go-to-k/cdkd/issues/4138))** -- `src/deployment/rollback-executor.ts`. On a rollback arm that never resolves a record's name, an AWS message quoting that name alone is masked only through the id's name segments. Those came from a per-shape list, and each review found another shape: an MSK cluster or AppRunner service name before a UUID or hex id, an EKS nodegroup name mid-path, and a WAFv2 name first in `<Name>|<Id>|<Scope>`. Every segment of an ARN's resource part (after its resource-type word) and of a `|` composite is now a needle, except the shapes AWS generates: numbers, UUIDs, 16+ character hex ids, WAF scope words and Cognito user pool ids. A Lambda ARN still takes only the name after `function:` / `layer:`, never an alias qualifier. Tests: `tests/unit/deployment/rollback-executor-derived-name-mask.test.ts`.

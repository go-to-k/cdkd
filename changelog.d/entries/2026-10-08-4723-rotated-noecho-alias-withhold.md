- **`cdkd diff` no longer prints a rotated `NoEcho` parameter's previous value inside the name of a stale export alias's REMOVE row** (`src/analyzer/outputs-diff.ts`, `src/cli/commands/diff-recursive.ts`, go-to-k/cdkd#4723). An older binary that published `Export.Name: {Fn::Sub: 'x-${Short}-y'}` while the `NoEcho` parameter `Short` held `ab` left the alias `x-ab-y` in state; after the value rotated, the diff withheld only a stored name equal to today's refused name (`x-cd-y`) and printed `x-ab-y` in the human rows and in `--json`. While any declared output (condition-skipped and failed ones included) has an intrinsic `Export.Name` reading a `NoEcho` parameter, the name of every stored alias today's template cannot account for is now withheld: a key the record's `exportNames` lists, or any such key when the record lists none. The row is still reported. The rule is stack-wide because state records no alias's owner; a stack where no declared name reads a `NoEcho` parameter prints its stale aliases as before. This also withholds the stored alias of a condition-false exporter, which spelled today's short value and printed. Tests: `tests/unit/cli/diff-rotated-noecho-alias-4723.test.ts`.

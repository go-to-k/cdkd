- **Under `--aws-emulator`, a `cr.Provider`'s `onEvent` / `isComplete` handlers and its waiter state machine run in the official Lambda runtime image too (issue [#6213](https://github.com/go-to-k/cdkd/issues/6213))** -- `src/local/custom-resource-second-hop.ts` (new), `src/local/custom-resource-waiter.ts` (new), `src/local/custom-resource-runtime.ts`, `src/local/custom-resource-runtime-gate.ts` (`withCustomResourceStack`), `src/local/docker-runner.ts` (`envAfterWiring`, `extraLoopbackPorts`, `dockerBridgeGateway`), `src/cli/commands/destroy-runner/run.ts`, unit tests and docs. Before, the framework function ran locally (#6206) but its `lambda:Invoke` of the user's handler, and the `isComplete` waiter's Step Functions execution, still ran in AWS Emulator's embedded runtime, so a handler needing `https` (Node.js) or `_signal` (Python) failed, and so did every `isCompleteHandler` provider (the waiter's framework functions submit the response over `https`). Now every container the local custom-resource runtime starts gets a cdkd endpoint on the host's loopback as `AWS_ENDPOINT_URL_LAMBDA` / `AWS_ENDPOINT_URL_SFN`: a synchronous invoke of a function the caller's environment names by `Fn::GetAtt` / `Ref` in the same stack runs locally with #6206's rules, a `StartExecution` of CDK's waiter state machine runs that state machine locally (Retry / Catch), and every other call is signed again with the emulator's keys and sent to the emulator. The endpoint is used with an emulator on `127.0.0.1` only, and accepts only requests carrying the container's token and a SigV4 signature made with the emulator's keys over the body received, dated within 15 minutes. A function the caller names that cannot run locally gets one warning; a local run that fails answers as a function error rather than a retried 5xx; when containers cannot reach the endpoint, cdkd warns once and runs the handlers in the emulator. A destroy now resolves a custom resource's function in the stack it destroys, not a same-named one of another stack. Real AWS deploys are unchanged.

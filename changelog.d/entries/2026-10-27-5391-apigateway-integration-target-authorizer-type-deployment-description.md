- **API Gateway REST `Method` `Integration.IntegrationTarget` is now sent, and an `Authorizer` `Type` change and a `Deployment` `Description` change are applied in place (issue [#5391](https://github.com/go-to-k/cdkd/issues/5391))** -- `src/provisioning/providers/apigateway-provider.ts`. A private integration's `IntegrationTarget` (the load balancer behind a VPC link) never reached `PutIntegration`, on create or update. Changing an `AWS::ApiGateway::Authorizer`'s `Type` sent nothing and reported success; it is now patched in place (`replace /type`). Changing an `AWS::ApiGateway::Deployment`'s `Description` failed the deploy; it is now patched in place (`replace /description`), and a removed description is cleared. A CloudFormation A/B in us-east-1 updated both in place (same authorizer and deployment ids) and cleared a removed deployment description.

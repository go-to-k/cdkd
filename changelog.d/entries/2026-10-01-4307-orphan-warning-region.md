- **The KMS, Cognito user pool and AppSync orphan warnings now paste their `aws` commands with `--region` (issue [#4307](https://github.com/go-to-k/cdkd/issues/4307))** -- `src/provisioning/providers/{kms,cognito,appsync}-provider.ts`. After a create attempt failed without a definite answer (or a KMS follow-up call failed after `CreateKey`), these warnings name the possibly-orphaned resource and give `describe` / `get` / `delete` commands to paste. The commands carried no `--region`, so for a stack deployed outside the shell's default region they ran against the wrong region: a describe answered NotFound and read as "no orphan", leaving a billed duplicate in place. Each command now carries the region of the client that created or listed the resource; when that region cannot be read, the warning is still printed without the fragment. Tests: `tests/unit/provisioning/{kms,cognito,appsync}-create-retry-2080.test.ts`.

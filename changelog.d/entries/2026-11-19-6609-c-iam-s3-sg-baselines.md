- **An IAM role, user, group, managed policy or instance profile member, an S3 bucket policy, an event bus `Policy` or a security group rule that cdkd just wrote no longer leaves a drift baseline that `cdkd drift --revert` would undo when the write is not yet visible (issue [#6609](https://github.com/go-to-k/cdkd/issues/6609))** -- `src/provisioning/settle-own-write-members.ts`, `src/provisioning/sg-own-write-rules.ts`, `src/provisioning/providers/{iam-role,iam-managed-policy,iam-user-group}/read-state.ts`, `src/provisioning/providers/iam-instance-profile-provider.ts`, `src/provisioning/providers/s3-bucket-policy-own-write.ts`, `src/provisioning/providers/eventbridge-bus-provider.ts`, `src/provisioning/providers/ec2/read-state.ts`, unit tests. The deploy recorded the first read after the write as the `observedProperties` baseline. The capture after cdkd's own write now re-reads a declared member whose first answer differs from the template (up to 3 more reads, 3.5 seconds at most, only when the first answer differs; the member's own call): a role's `AssumeRolePolicyDocument`, `PermissionsBoundary`, `ManagedPolicyArns` and inline `Policies`, a user's `PermissionsBoundary`, `ManagedPolicyArns`, `Groups` and `Policies`, a group's `ManagedPolicyArns` and `Policies`, a managed policy's `PolicyDocument` and `Roles` / `Users` / `Groups`, an instance profile's `Roles`, a bucket policy, an event bus `Policy`, and a security group's `SecurityGroupIngress` / `SecurityGroupEgress`. A list is settled once every declared entry reads back (an entry the template does not declare, such as one another resource of the stack owns, never holds it; an event bus `Policy` likewise once every declared statement reads back). A list still read empty, a boundary or an event bus policy still unset is recorded as declared, and a bucket policy still absent records no baseline, so drift compares it against the template. Any other answer, a list missing only some declared entries included, is recorded as read. Either way a warning names the resource and member and points at `cdkd state refresh-observed`. Drift, import and `state refresh-observed` still take the first answer.

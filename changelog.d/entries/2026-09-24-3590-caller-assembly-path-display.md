- **Containment refusals and absolute-path warnings no longer quote the value the assembly chose in quotes of cdkd's own (issue [#3590](https://github.com/go-to-k/cdkd/issues/3590))** -- the subject of each refusal (`Metadata['aws:asset:path']=`, `templateFile=`, an asset manifest's `file=`, `source.path=`, `source.directory=`, `Stack metadata file`, an inline `Handler`), the nested-template chain and cycle messages, the `cdkd synth --verbose` symbolic-link refusal, and the absolute-path, whole-assembly and Stage-root warnings in `src/synthesis/`, `src/assets/`, `src/local/lambda-resolver.ts`, `src/utils/nested-template-cycle.ts`, `src/provisioning/providers/nested-stack-provider.ts` and `src/cli/commands/` (`diff-recursive`, `export`, `local-invoke`, `synth`, `emulator-docker-context`). These printed the value inside `'...'`, and the sanitizer passes `'`, so a crafted value could close the quote and write a clause of its own. Each now renders through `displayAssemblyPath` (go-to-k/cdkd#3509): a plain path bare (`Metadata['aws:asset:path']=../../etc/passwd which ...`), anything else as one JSON string. `cdkd import`'s two sites are the remainder, tracked on #3590.

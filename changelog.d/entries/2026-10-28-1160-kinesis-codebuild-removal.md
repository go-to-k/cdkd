- **`AWS::Kinesis::Stream` / `AWS::CodeBuild::Project`: a removed `MaxRecordSizeInKiB`, `EncryptionKey` or `Tags` is now reset as CloudFormation resets it (issue [#1160](https://github.com/go-to-k/cdkd/issues/1160))** -- `src/provisioning/providers/kinesis-provider.ts` and `src/provisioning/providers/codebuild-provider.ts`, with unit tests in `tests/unit/provisioning/kinesis-provider-record-size-removal-1160.test.ts` and `tests/unit/provisioning/codebuild-provider-removal-1160.test.ts`. Before, dropping these properties from the template left the old value live, and the next `cdkd diff` showed no change. A CloudFormation A/B showed that CloudFormation resets a removed `MaxRecordSizeInKiB` to 1024, a removed CodeBuild `EncryptionKey` to the AWS managed S3 key (`alias/aws/s3`), and removes every tag when `Tags` is removed. cdkd now sends the same values. A removed CodeBuild `SourceVersion` is kept, because CloudFormation keeps it too.

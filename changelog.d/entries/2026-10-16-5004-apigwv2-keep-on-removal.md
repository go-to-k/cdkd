- **Removing an ApiGatewayV2 property from a template no longer resets properties CloudFormation keeps (issue [#5004](https://github.com/go-to-k/cdkd/issues/5004))** -- A real CloudFormation A/B showed CloudFormation leaves the live value of these when they are dropped from the template, so cdkd now sends nothing for them either (the live value stays): Api `Description`, `Version`, `DisableExecuteApiEndpoint`, `IpAddressType`, `ApiKeySelectionExpression`; Stage `StageVariables` (per key), `ClientCertificateId`; Integration `Description`, `RequestParameters` (per key); Route `AuthorizationType`, `AuthorizerId`, `OperationName`, `RequestModels` and `RequestParameters` (per key, no more `DeleteRouteRequestParameter`); Authorizer `AuthorizerCredentialsArn`, `AuthorizerPayloadFormatVersion`, `AuthorizerResultTtlInSeconds`, `IdentityValidationExpression`. Api `CorsConfiguration`, Stage `AutoDeploy` / `AccessLogSettings` / `RouteSettings` and Route `AuthorizationScopes` are reset by CloudFormation too and keep their resets. Changed: `src/provisioning/providers/apigatewayv2-provider.ts`, `docs/provider-rules.md`, the `apigatewayv2-update-removal` integ fixture and the ApiGatewayV2 unit tests.

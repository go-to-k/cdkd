- **Updating a Lambda function that is still `Pending` no longer fails the deploy (issue [#6605](https://github.com/go-to-k/cdkd/issues/6605))** -- `src/provisioning/providers/lambda-function/update.ts`, `src/deployment/retryable-errors/patterns.ts`, `tests/unit/provisioning/lambda-function-update-pending-6605.test.ts`, `tests/integration/lambda-vpc-update-while-pending/`. cdkd's create returns before a function is `Active`, and a VPC function stays `Pending` for minutes. An update in that window was refused by AWS with `...is currently in the following state: 'Pending'`, which the retry table's unquoted spelling never matched, so the deploy failed with `ResourceConflictException` and rolled back. When AWS refuses an update call for that reason, `update()` now waits for `Active` (up to 10 minutes) and sends the call again. An update AWS does not refuse makes no extra call. The retry table also matches the quoted spelling, and the `destroy-interrupt` fixture's stall check reads both spellings.

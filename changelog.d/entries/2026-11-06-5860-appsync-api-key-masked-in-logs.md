- **The AppSync provider no longer prints an `AWS::AppSync::ApiKey`'s full key in a log line or error message (issue [#5860](https://github.com/go-to-k/cdkd/issues/5860))** -- `src/provisioning/providers/appsync/` (`api-key.ts`, `clients.ts`, `errors-delete.ts`, `shared.ts`, `update-children.ts`). The key id IS the credential a client sends as `x-api-key`. Before this change, `--verbose` debug lines on create, delete and `getAttribute`, the ARN-build / attribute-rebuild warnings on create, update and import, the malformed-id refusals on update and delete, and the cross-region import refusal printed it in clear. Each now shows only its last four characters (`****wxyz`), the form the orphan report already used, and AWS failure text that quotes the key back is masked the same way.

- **`cdkd drift` reports an FSx Windows alias that failed to associate or is being removed (issue [#6854](https://github.com/go-to-k/cdkd/issues/6854))** -- `src/provisioning/providers/fsx-filesystem/read-state.ts`. The readback listed every alias name whatever its lifecycle, so a declared alias in `CREATE_FAILED` or `DELETING` compared equal. Those two are no longer read as the file system's names, so the alias reads as drift and `cdkd drift --revert` re-associates it.

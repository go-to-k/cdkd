- **A value that cannot be converted to text no longer defeats `cdkd local start-api`'s graceful shutdown or hides a failed `--watch` reload** (`src/cli/commands/local-start-api.ts`, go-to-k/cdkd#3361). The `uncaughtException` and `unhandledRejection` listeners, and the reload's synth catch, rendered the value they received with a bare `String()`, which throws for a null-prototype object. A throw inside the `uncaughtException` listener ended the process without the shutdown that removes the warm containers and the profile credentials tmpdir; the `unhandledRejection` listener reported the converter's `TypeError` instead of the rejection; and a failed re-synth printed nothing, because the reload chain swallowed the `TypeError` in place of the "keeping previous version" warning. Each now renders through `safeStringify` / `describeAwsFailure(x).detail`, byte-identical whenever the value converts and a placeholder only when it cannot. Tests: `tests/unit/cli/local-start-api-string-outthrow-3361.test.ts`.

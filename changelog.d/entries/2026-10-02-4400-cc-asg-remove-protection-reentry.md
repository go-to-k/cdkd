- **`cdkd destroy --remove-protection` now restores a Cloud Control-routed Auto Scaling group's guards after a retry that later fails terminally (issue [#4400](https://github.com/go-to-k/cdkd/issues/4400))** -- `src/provisioning/cloud-control-provider.ts`. A group recorded as `provisionedBy: cc-api` is deleted through the SDK Auto Scaling provider, which was built afresh on every attempt and so forgot what an earlier attempt had turned off. When one attempt turned the group's `DeletionProtection` and its instances' `DisableApiTermination` off and failed retryably, and the next failed terminally, neither guard was turned back on. The delegate is now kept for the Cloud Control provider's lifetime (one per region), as the SDK route already did, so the terminal failure restores both. Tests: `tests/unit/provisioning/cloud-control-asg-delegate-reuse-4400.test.ts`.

- **`cdkd local start-alb` serves a listener rule whose `host-header` condition is the load balancer's own DNS name, and no longer widens a rule whose condition value it cannot resolve (issue [#5797](https://github.com/go-to-k/cdkd/issues/5797))** -- `package.json` (`cdk-local` `^0.158.1` -> `^0.158.2`), `docs/local-start-alb.md`. Before this change, a condition value that was not a literal string was dropped. A rule like `ListenerCondition.hostHeaders([alb.loadBalancerDnsName])` behind a fixed-403 default action was skipped, so the service behind it was unreachable, and a rule pairing an unresolvable value (a `Ref` to a parameter, for example) with a `path-pattern` matched on the path alone. Now the load balancer's own DNS name matches any `Host`, and any other unresolvable value skips the whole rule with a warning.

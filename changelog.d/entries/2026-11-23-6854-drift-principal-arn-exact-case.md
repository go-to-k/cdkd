- **`cdkd drift` no longer matches a resource policy principal's IAM unique id to an ARN spelled in another case (issue [#6854](https://github.com/go-to-k/cdkd/issues/6854))** -- `src/cli/commands/drift/command.ts`, `tests/unit/cli/drift-bucket-policy-recorded-principal-6680.test.ts`. Drift proves an `AROA…` / `AIDA…` id equal to a recorded role or user ARN by looking the principal up by name, and accepted the answer when its ARN matched ignoring case. IAM and S3 refuse a principal ARN whose role name or path differs from the role's only in case, so such an ARN names a different principal; the id and the ARN now compare equal only when the ARN matches exactly, and otherwise the difference is reported as drift.

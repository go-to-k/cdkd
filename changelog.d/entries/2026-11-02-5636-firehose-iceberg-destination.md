- **`AWS::KinesisFirehose::DeliveryStream` sends `IcebergDestinationConfiguration` on the SDK route (issue [#5636](https://github.com/go-to-k/cdkd/issues/5636))** -- `src/provisioning/providers/firehose-provider.ts` forwards the block on `CreateDeliveryStream` and reads it back for drift, so a stream declaring it no longer falls back to Cloud Control. CloudFormation's `s3BackupMode` and `CatalogConfiguration.CatalogArn` are sent as the SDK's `S3BackupMode` and `CatalogARN`; the in-place update used to send both under CloudFormation's spelling, and now sends the backup mode correctly and leaves out the create-only catalog. `SnowflakeDestinationConfiguration`, `MSKSourceConfiguration` and `DatabaseSourceConfiguration` still route through Cloud Control.

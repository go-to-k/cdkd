- **`AWS::KinesisFirehose::DeliveryStream` sends `IcebergDestinationConfiguration` on the SDK route (issue [#5636](https://github.com/go-to-k/cdkd/issues/5636))** -- `src/provisioning/providers/firehose-provider.ts` forwards the block on `CreateDeliveryStream` and reads it back for drift, so a newly deployed stream declaring it no longer falls back to Cloud Control (an existing stream keeps its recorded Cloud Control route). CloudFormation's `s3BackupMode` and `CatalogConfiguration.CatalogArn` are sent as the SDK's `S3BackupMode` and `CatalogARN`. The in-place update used to drop the backup mode (it read `S3BackupMode`, which a template never holds) and sent the catalog under CloudFormation's `CatalogArn`; it now sends the mode and leaves out the create-only catalog. `SnowflakeDestinationConfiguration`, `MSKSourceConfiguration` and `DatabaseSourceConfiguration` still route through Cloud Control.

- **`cdkd drift` no longer reads an event source mapping on a function alias or version as one on a function named after the qualifier (issue [#6854](https://github.com/go-to-k/cdkd/issues/6854))** -- `src/provisioning/providers/lambda-eventsource/read-state.ts`. The readback echoed a recorded bare `FunctionName` when the live ARN's LAST segment matched it; on `arn:...:function:other-fn:prod` that segment is the qualifier, so a mapping moved to `other-fn:prod` compared equal to a record naming a function `prod`. The bare name is now echoed only for that function's unqualified ARN.

- **`cdkd diff` and the deploy approval prompt no longer hint `moved to ..., run 'cdkd refactor' to keep it` for a removed resource whose replacement targets a different existing resource (issue [#6797](https://github.com/go-to-k/cdkd/issues/6797))** -- `src/analyzer/refactor-hints.ts`, `src/cli/commands/diff-recursive/build-tree.ts`, `src/deployment/deployment-approval.ts`, `tests/unit/analyzer/refactor-hints.test.ts`. Moving an SNS subscription from one existing queue to another hinted the old subscription and queue policy as moved, because the hint matched an unresolved `Ref` / `Fn::GetAtt` to anything, and `cdkd refactor` then refused the pair. A new resource that references a resource staying in the stack is now hinted only against a record that referenced that same resource; a record from before `dependencies` was recorded keeps the old, looser match.

- **`cdkd local start-api` resolves a REST v1 `CognitoUserPoolsAuthorizer`'s user pool from `--from-state` / `--from-cfn-stack`, and warns per route for every auth setting it does not enforce (issue [#6717](https://github.com/go-to-k/cdkd/issues/6717))** -- `src/cli/commands/local-start-api/{command,state}.ts`, cdk-local 0.169.1. The authorizer names its pool as `Fn::GetAtt <Pool>.Arn`; with a state source it now verifies tokens against the deployed pool's JWKS, and the stack's state is loaded for it even when no Lambda there is routed. Without one it still serves, warned once per route. A REST method's `ApiKeyRequired`, `AuthorizationScopes` on a REST method or HTTP route, a TOKEN authorizer's `IdentityValidationExpression` and a RestApi `Policy` now warn per route at startup instead of being ignored silently.

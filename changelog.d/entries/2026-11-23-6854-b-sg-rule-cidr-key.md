- **A security group rule's CIDR is compared as EC2 stores it (issue [#6854](https://github.com/go-to-k/cdkd/issues/6854))** -- `src/provisioning/providers/ec2/sg-rule-by-id.ts`. The standalone ingress readback's CIDR key read a prefix with no digits (`10.0.0.0/`) as `/0`, the key of `0.0.0.0/0`; it is now compared as written. The IPv6 key now clears host bits, as EC2 does (measured: `2001:db8::5/64` is stored as `2001:db8::/64`), so a record spelled with host bits no longer reads as a moved rule.

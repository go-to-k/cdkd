- **`cdkd drift --revert` stops shipping two wrong values to live AWS, and its mask refusal names the right remedy** ([#2855](https://github.com/go-to-k/cdkd/issues/2855), [#2893](https://github.com/go-to-k/cdkd/issues/2893), [#2881](https://github.com/go-to-k/cdkd/issues/2881); all in `src/cli/commands/drift.ts`).

  **#2855** — a record refused an `observedProperties` baseline (#2842) falls back to raw `properties` holding intrinsic OBJECTS (`{Fn::Join: ...}`) from `cdkd import`'s warn path, and the revert pushed the raw object live. Measured with mocked SDKs: no route fails loudly — the SDK route puts the object into the wire call, Cloud Control emits it as a patch value, and a JSON-string property stringifies it into a schema-VALID string AWS accepts silently. The revert now REFUSES such a resource before `provider.update` (exit `2`, remedy: `cdkd deploy`), scanning the BASELINE at drifted top-level keys, only for records with NO observed baseline (`collectUnresolvedIntrinsicObjectPaths`).

  **#2893** — `preserveLiveValuesAtUnresolvedTokens` paired array elements POSITIONALLY behind a length test, so a reordered readback copied another element's live value into a token position. It now pairs through the masked-leaf walk's `pairedLiveItems` rule (identity first, else per-leaf frame corroboration), wildcard per caller; on refusal the token is KEPT — this pass's residual — except a 1-vs-1 array, a FORCED position where refusal would destroy the live value, so it is preserved as before. Closes the token half of #2884 (PR #2882 closed the masked half).

  **#2881** — the mask refusal asserted "(a NoEcho custom-resource value)" and prescribed a nonce bump, wrong for the now-common #2852 fail-closed cause. It now names both causes and remedies; both token warnings state the pairing condition (partial: that issue's other messages stay open on it).

The Phase 1B refusal told the operator to clear cdkd state "for the migrated stacks via 'cdkd state orphan <stack>'": a command with no `--stack-region`, which drops that stack name's record in every region, built outside the shared pasteable-command gate, and with no word on which records to clear or when -- clearing the failed parent's record before its phase 2 ran drops cdkd's only record of what phase 2 would have created.

- **`cdkd local` with `--from-state` / `--from-cfn-stack` now resolves SSM list parameters and SSM parameters of an AWS-specific type (PR [#6322](https://github.com/go-to-k/cdkd/pull/6322))** -- `package.json` (`cdk-local` `^0.167.2` -> `^0.168.0`, with go-to-k/cdk-local#977). A `Ref` to an `AWS::SSM::Parameter::Value<List<String>>` (or `CommaDelimitedList`) parameter resolves to the comma-split list, so `Fn::Select` / `Fn::Join` over it work locally as they do on deploy; and `Value<AWS::EC2::Image::Id>` (`ec2.MachineImage.fromSsmParameter`) and the other `Value<AWS-specific type>` forms are read from SSM instead of being dropped with a warning. An env var set directly to a list parameter is still dropped with a warning, as CloudFormation refuses it too. No cdkd source change.

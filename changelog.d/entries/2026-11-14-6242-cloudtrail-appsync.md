- **`Fn::GetAtt` of a CloudTrail trail's `SnsTopicArn` and an AppSync API's `GraphQLEndpointArn` / `RealtimeUrl` now returns the value CloudFormation returns (issue [#6242](https://github.com/go-to-k/cdkd/issues/6242))** -- the CloudTrail provider's create / update / import, the AppSync GraphQL API create / import, `src/deployment/intrinsic-resolver/getatt-construct-app.ts`, unit tests and a new `getatt-cloudtrail-appsync` integ fixture. CDK's `trail.trailSnsTopicArn` used to resolve to the trail's own ARN, and an API's `graphQLEndpointArn` / `RealtimeUrl` failed the deploy. Now the trail records the ARN of the topic it notifies (also after an update moves it to another topic), and the AppSync two are built on the API's endpoint id, which AppSync serves its host names under (it is not the API id), as measured against CloudFormation.

- **`AWS::DynamoDB::Table` updates now apply `DeletionProtectionEnabled` and refuse a `LocalSecondaryIndexes` change (issue [#5354](https://github.com/go-to-k/cdkd/issues/5354))** -- `src/provisioning/providers/dynamodb-table-provider.ts`, `src/analyzer/replacement-rules.ts`. A deploy that turned deletion protection on or off used to succeed while the table kept its old setting; it is now sent with `UpdateTable`, and removing the property turns protection off, as CloudFormation does. A string `'true'` / `'false'` is sent as a boolean on create and update, and a value that is not a boolean is refused before any call. A change to `LocalSecondaryIndexes` (adding, removing or changing an index) used to be dropped while the deploy succeeded; DynamoDB cannot change a local secondary index on an existing table and CloudFormation fails the same update without replacing the table, so cdkd now refuses it before any call.

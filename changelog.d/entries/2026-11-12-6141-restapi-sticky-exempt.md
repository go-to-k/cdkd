- **An `AWS::ApiGateway::RestApi` recorded `provisionedBy: 'cc-api'` now returns to its SDK provider on its next mutating deploy (issue [#6141](https://github.com/go-to-k/cdkd/issues/6141))** -- `src/provisioning/provider-registry.ts` and the new `cc-to-sdk-reroute-rest-api` integ. A REST API deployed before [#6139](https://github.com/go-to-k/cdkd/issues/6139) kept the polled Cloud Control update; the type is now admitted to the `'sdk-coverage'` sticky exemption, so such a stack takes the synchronous SDK path. Both layers record the bare REST API id, so the id and `RootResourceId` are unchanged and the API is updated in place. `cdkd diff` annotates the move `[returning to SDK provider]`, and `--pin-cc-api <LogicalId>` declines it.

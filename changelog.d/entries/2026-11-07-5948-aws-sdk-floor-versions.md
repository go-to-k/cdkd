- **Runtime AWS SDK dependency floors raised to the versions cdkd is built and tested against (issue [#5948](https://github.com/go-to-k/cdkd/issues/5948))** -- `package.json`, `.github/dependabot.yml`. Every `@aws-sdk/*` and `@smithy/*` runtime dependency now declares the version locked in `pnpm-lock.yaml` as its caret floor (`^3.1161.0` for the clients). Before, floors such as `@aws-sdk/client-kinesis` `^3.1018.0` let a project that already had an older client installed (for example through `@aws-amplify/analytics`) reuse it for cdkd, and every cdkd command crashed at startup with `SyntaxError: Named export 'UpdateStreamRecordDistributionStrategyCommand' not found` because that command first shipped in 3.1139.0. Dependabot now raises the declared floor together with the lockfile (`versioning-strategy: increase`), so the floor no longer falls behind the client the code compiles against.

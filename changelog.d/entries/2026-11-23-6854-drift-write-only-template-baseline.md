- **`cdkd drift` no longer reports a declared write-only property as removed on a resource with no drift baseline (issue [#6854](https://github.com/go-to-k/cdkd/issues/6854))** -- `src/cli/commands/drift/compare.ts`, `src/cli/commands/drift/detect.ts`, `src/cli/commands/drift/baseline-keys.ts`, `tests/unit/cli/drift-write-only-template-baseline-6854.test.ts`. A Cloud Control read never returns a write-only property, so a Cloud Control resource compared against its template reported every declared write-only property removed on each run. Those schema paths are now left out on that baseline, as CloudFormation drift leaves them out; every other property is compared as before.

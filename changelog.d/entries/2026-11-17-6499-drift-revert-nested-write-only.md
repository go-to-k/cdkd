- **`cdkd drift --revert` works on a Cloud Control resource whose property holds a nested write-only field, such as an EventBridge connection's API key (issue [#6499](https://github.com/go-to-k/cdkd/issues/6499))** -- `src/cli/commands/drift/{plan,revert,revert-outcome,revert-payload}.ts`. AWS never returns a write-only field on a read, and the revert built its request from the read, so an `AWS::Events::Connection`'s `AuthParameters` went out without `ApiKeyValue` and Cloud Control refused every revert of a connection (`required key [ApiKeyValue] not found`). The revert now sends the template's value of each property that holds a write-only field, as a deploy does, and the plan names those properties before the confirmation. A `{{resolve:...}}` value is sent resolved and stays masked in the output; one cdkd cannot resolve is not sent. This also covers a top-level write-only value held in a dynamic reference, which the fix for [#6498](https://github.com/go-to-k/cdkd/issues/6498) left out.

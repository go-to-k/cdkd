- **Removing a subnet's `MapPublicIpOnLaunch` keeps its live value, as CloudFormation does** (Closes #6342). The `AWS::EC2::Subnet` update used to read an absent value as `false` and send `ModifySubnetAttribute false`. A live A/B (us-east-1) showed that CloudFormation keeps the current value on that removal. An absent desired value now sends nothing, as for `EnableDns64`. A declared value is still applied, including `false` over a record that holds no value, and the CloudFormation string spellings (`"true"`, `"False"`) are coerced on create and update. A malformed value (for example `"yes"`) is refused before any call; a rollback replay keeps the previous value and warns. Adds unit coverage and a `subnet-mappublicip-removal` integration fixture.

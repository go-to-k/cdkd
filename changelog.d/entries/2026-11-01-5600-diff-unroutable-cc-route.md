- **`cdkd diff` no longer predicts a Cloud Control route the type does not have (issue [#5600](https://github.com/go-to-k/cdkd/issues/5600))** -- `src/cli/commands/diff-recursive.ts` left `[via CC API: <Prop>]` and the `--json` `ccApi` field on a resource whose type has no Cloud Control route, such as `AWS::CodeBuild::Project` with `Triggers`, which `cdkd deploy` refuses pre-flight. The row now carries no route, and the diff warns that a deploy without `--prefer-sdk-route` refuses the property. It is a warning rather than exit 3, because a deploy with the flag goes through. Both read `ProviderRegistry.ccRouteUnavailableReason`, the predicate the refusal reads.

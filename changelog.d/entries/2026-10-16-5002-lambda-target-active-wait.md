- **Deploying an `AWS::ElasticLoadBalancingV2::TargetGroup` with `TargetType: lambda` no longer fails intermittently with "Lambda function ... is not in Active state" (issue [#5002](https://github.com/go-to-k/cdkd/issues/5002)).** The function's create returns while it is still `Pending`, and ELBv2 rejects registering a `Pending` function, so the first deploy sometimes rolled back and a re-run passed. The target group now waits for each Lambda target to reach `State=Active` immediately before `RegisterTargets` (create and update); no other target group and no Lambda create pays for it. A function that ends `Failed` or never turns Active fails the target group with an error naming the function, without AWS's message text. Source: `src/provisioning/providers/elbv2-provider.ts`, `src/provisioning/providers/custom-resource-provider.ts`.

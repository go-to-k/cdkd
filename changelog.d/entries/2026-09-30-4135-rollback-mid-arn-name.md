- **A rollback no longer prints a secret-derived ELBv2 or Lambda name that an AWS message quotes on its own (issue [#4135](https://github.com/go-to-k/cdkd/issues/4135))** -- `src/deployment/rollback-executor.ts`. On a rollback arm that never resolves a record's name, only the id's NAME segment can mask such a message, and that segment was the ARN's last one. An ELBv2 load balancer or target group keeps its name before a `/<hash>`, and a Lambda ARN keeps its function name before a `:<version>` / `:<alias>` qualifier, so a message quoting the name alone printed it. Taking the qualifier also masked an alias word such as `production` in the same op's prose. Both services now take the segment where their name sits. Tests: `tests/unit/deployment/rollback-executor-derived-name-mask.test.ts`.

- **`-c` / `--context` now takes one value per flag, so `cdkd deploy -c env=prod MyStack` deploys `MyStack`, as `cdk deploy` does (issue [#6905](https://github.com/go-to-k/cdkd/issues/6905))** -- `src/cli/options.ts`, `src/cli/commands/export.ts`, `tests/unit/cli/single-value-repeatable-flags-6905.test.ts`. The flag was variadic, so it consumed every argument after it: a stack name written after `-c key=value` became a context value, and a multi-stack app then refused with "Specify stack name(s) or use --all" (a single-stack app deployed its one stack). The AWS CDK CLI declares `--context` with one value per flag. `cdkd export --parameter` and `--cfn-child-stack-name` change the same way. Repeat the flag for several values (`-c a=1 -c b=2`); `-c a=1 b=2` now reads `b=2` as a stack name, as the CDK CLI does.

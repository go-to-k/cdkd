State redaction matched secrets by value: `Engine: postgres` became the username reference, and so did the text of `Fn::Join ['', ['postgresql://', <endpoint>, '/postgres']]`, which every next diff then read as a change (`Engine` as a refused stateful replacement). Text the template writes is now stored as written, inside `Fn::Join`, `Fn::Sub` (and its variable map), `Fn::Select` / `Fn::Split` and `Fn::If` too. Parts supplied by a reference are stored as the reference, which also closes a 1-3 character secret in an `Fn::Sub` variable that was stored in plaintext. **Already-affected state:** `cdkd deploy` reads the stored reference before planning and compares the record as the template's text when the secret proves it, unless the secret has rotated since. The record is then repaired without sending anything. `cdkd scrub` also repairs a plain-string position. `cdkd diff` reads no secret, so it keeps showing the old row until then, with a warning naming `cdkd scrub <stack>`.

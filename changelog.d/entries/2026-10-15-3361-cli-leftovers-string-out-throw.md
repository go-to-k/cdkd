- **A failure value that cannot be converted to text no longer turns a best-effort step of `cdkd diff`, the `--recreate-via-*` consumer listing, `cdkd bootstrap --destroy` or `cdkd publish-assets` into a hard failure** (`src/analyzer/outputs-diff.ts`, `src/cli/commands/{recreate-downstream-consumers,bootstrap-destroy,publish-assets}.ts`, go-to-k/cdkd#3361). `String()` throws for a null-prototype object, and these handlers built their message with it, so the handler itself threw: an output value or `Export.Name` that `cdkd diff` could not resolve failed the diff instead of being skipped; one unreadable state file, or a failed stack listing, failed the downstream-consumer enumeration instead of being skipped or falling back to an empty list; a failed bootstrap-marker listing failed `bootstrap --destroy` instead of warning and continuing; and, with more than one stack selected, one stack's failure in `cdkd publish-assets` stopped the run instead of being recorded while the remaining stacks were published. Each now goes through `describeAwsFailure(x).detail` or `safeStringify(x)`, byte-identical for every value `String()` converts and a placeholder otherwise. Tests: `tests/unit/{analyzer/outputs-diff,cli/recreate-downstream-consumers,cli/bootstrap-destroy,cli/publish-assets}-string-outthrow-3361.test.ts`.

- **`broadening` no longer depends on a CDK library (issue [#4601](https://github.com/go-to-k/cdkd/issues/4601))** -- `src/analyzer/security-changes.ts` (new), `src/analyzer/security-diff.ts`, `package.json`. `cdkd diff --fail-on=broadening` and `cdkd deploy --require-approval=broadening` read their verdict and security table from `@aws-cdk/cloudformation-diff`, a runtime dependency since 0.298.0. They now use cdkd's own classifier, which follows the AWS CDK CLI's rules for IAM statements, managed-policy attachments, `AWS::Lambda::Permission`, IAM Identity Center and security-group rules. The verdict and the printed table (text and colors) are unchanged, except that text the CDK CLI's table could not lay out (a combining mark, a control character, a ZWJ emoji) is now printed rather than dropped or replaced by a note, and `@aws-cdk/cloudformation-diff` is gone from cdkd's dependencies (it remains a devDependency for tests). Tests: `tests/unit/analyzer/security-changes-parity.test.ts` (new) runs both classifiers over 84 template pairs, with and without colors, and requires the same verdict and table, and requires cdkd's table of scrutinized resource types and properties to match the AWS service-spec database.

DynamoDB `StreamArn` and IAM Role `RoleId` (when the state record lacks them and the re-read does not supply them), a Cloud Map DNS namespace `HostedZoneId` whose `GetNamespace` read fails or reports none, and `AWS::IAM::Policy` `PolicyId` / `AWS::ServiceDiscovery::HttpNamespace` `HostedZoneId` (attributes CloudFormation does not define) used to resolve to `undefined`. CloudFormation rejects a template whose Output Value evaluates to `AWS::NoValue` ("The Value field of every Outputs member must evaluate to a String") before creating anything; cdkd now refuses it before provisioning too, with or without `--strict-getatt`, where it used to provision the stack and publish nothing for the Output.

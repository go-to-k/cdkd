- **Lambda, EventBridge bus and ECR creates no longer let the AWS SDK replay a 5xx inside one call (issue [#4639](https://github.com/go-to-k/cdkd/issues/4639), Lambda / EventBridge bus / ECR slice)** -- `src/provisioning/providers/lambda-create-client.ts` and the `lambda-function`, `lambda-url`, `lambda-permission`, `eventbridge-bus` and `ecr` providers. `CreateFunction`, `CreateFunctionUrlConfig`, `AddPermission`, `CreateEventBus` and `CreateRepository` carry no idempotency token and were sent through a client whose SDK retry replays a 5xx even when AWS completed the request. Each is unique by name, so the replay failed with "already exists" against the resource the first request made. That collision was credited to another holder, and the resource was left in no state record for every re-run to collide with. They now go through a dedicated client that refuses the SDK's 5xx retry (the CodeCommit / EC2 / IAM pattern). The 5xx reaches the deploy engine, which marks a later collision as possibly this create's own. Tests: `tests/unit/provisioning/lambda-ecr-create-retry-4639.test.ts`.

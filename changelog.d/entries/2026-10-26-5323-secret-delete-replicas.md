- **Destroying a Secrets Manager secret that still has replica regions succeeds (issue [#5323](https://github.com/go-to-k/cdkd/issues/5323))** -- `src/provisioning/providers/secretsmanager-secret-provider.ts`. `delete()` used to send `DeleteSecret` on the primary straight away, which Secrets Manager refuses with `InvalidParameterException` while the secret has replicas, so a stack holding a secret with `ReplicaRegions` could not be destroyed. On that refusal it now reads the secret's replica regions, removes them (`RemoveRegionsFromReplication`, which deletes each replica) and retries the delete, as CloudFormation does; an ordinary delete makes no extra call. Test: `tests/unit/provisioning/secretsmanager-secret-provider-delete-replicas-5323.test.ts`.

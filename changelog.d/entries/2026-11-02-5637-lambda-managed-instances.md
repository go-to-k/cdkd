- **Lambda Managed Instances functions deploy through the SDK provider (go-to-k/cdkd#5637)** -- `src/provisioning/providers/lambda-function-provider.ts`. `AWS::Lambda::Function` now wires `CapacityProviderConfig`, `FunctionScalingConfig` and `PublishToLatestPublished`, which used to send the whole function through Cloud Control. The capacity provider itself stays the separate `AWS::Lambda::CapacityProvider` resource: the function only takes its ARN. Measured against CloudFormation: a create always publishes `$LATEST.PUBLISHED` and waits for it (minutes, as the capacity launches), an update publishes unless `PublishToLatestPublished` is false, scaling applies to `$LATEST.PUBLISHED`, and removing the scaling block resets it to Lambda's default. Removing `CapacityProviderConfig`, and `FunctionScalingConfig` without one, are refused before any call, as CloudFormation refuses them. `cdkd drift` reads both properties back. A function already on Cloud Control stays there.

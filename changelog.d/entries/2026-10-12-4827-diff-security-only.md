- **`cdkd diff --security-only` (issue [#4827](https://github.com/go-to-k/cdkd/issues/4827))** -- `src/cli/commands/diff.ts`. The flag was refused as an unknown option, while `cdk diff --security-only` is valid. It now prints, instead of the diff, the AWS CDK CLI's warning and the security table (IAM and security-group changes, secret values shown as `***`) of every stack in each top-level tree that broadens permissions, and one line for a tree that does not. It walks nested stacks, refuses `--json`, and for `--fail-on` counts only the stacks it prints: `any-change` fails on a security change in a broadening tree, `broadening` fails without printing the tables twice, `destructive` still reads the whole diff. The security diff (#4601) is computed only when the flag or `--fail-on=broadening` asks. Tests: `tests/unit/cli/{diff-fail-on,diff-deploy-refusal-exit}.test.ts`; integ `require-approval-broadening`.

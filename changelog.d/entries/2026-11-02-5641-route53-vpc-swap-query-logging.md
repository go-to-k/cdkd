- **A hosted zone's VPC swap removes the old VPC, and a failed VPC or query logging change fails the deploy (go-to-k/cdkd#5641)** -- `src/provisioning/providers/route53-provider.ts`. Replacing a private zone's only VPC associated the new one but kept the old, because the last-VPC guard read the count from before the association. A failed associate, disassociate or query logging create was only warned about, so the deploy reported success with the template unapplied; each now fails as a `ProvisioningError` naming the logical id. An update also deleted and recreated an unchanged query logging config, which could lose it on a Comment-only change; it now leaves the config alone. `AWS::Route53::HostedZone` is no longer on Cloud Control's stale unsupported list.

- **The Glue, ACM certificate and Lambda MicroVM image import refusals no longer print a template value beside a `--resource` remedy (issue [#4273](https://github.com/go-to-k/cdkd/issues/4273))** -- `src/provisioning/providers/{glue,acm-certificate,lambda-microvm-image,ssm-parameter}-provider.ts`. The Glue Table warnings for an unpairable or ambiguous physical id, and the ACM / MicroVM "must be an ARN" refusals, showed the logical id raw or inside cdkd's own `'...'`, the supplied physical id inside `'...'`, and (Glue) the table and database names the ambiguity listed, on the same line as a `--resource` fragment. A `'`, `;` or `$( )` in the value ran when the line was pasted. Each value is now shown only when plain and described otherwise (`a logical id that is not a plain identifier`, `(not shown: it is not a plain identifier)`), and a `|` inside cdkd's quotes is still shown. The fragment names the logical id only when plain. A plain value prints as before. The rest of this rule landed with [#4226](https://github.com/go-to-k/cdkd/issues/4226).

- **`cdkd diff` no longer reports a phantom change when two regions or accounts share an SSM parameter name with different types (issue [#4105](https://github.com/go-to-k/cdkd/issues/4105))** -- `src/deployment/intrinsic-resolver/{dynamic-refs,cross-stack}.ts`, `src/deployment/secret-redaction/mask-only.ts`. cdkd remembered that a `{{resolve:ssm:...}}` reference pointed at a `SecureString` keyed by the token text alone. So once one stack's region answered `SecureString`, another stack whose region holds a plain `String` under the same name skipped its lookup on the comparison path: it compared the unresolved token against the resolved value in its state, and showed a change on every diff and deploy no-op check. A stack's comparison pass now reads only the verdict its own region and credentials pinned. The process-wide set the redaction path reads is unchanged. The `dynamic-ref-cross-region` integ gains a reversed mixed-type arm (phase 3f).

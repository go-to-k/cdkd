- **An `AWS::S3Tables::TableBucket`, `AWS::BedrockAgentCore::Runtime` or `AWS::BedrockAgentCore::Evaluator` recorded `provisionedBy: 'cc-api'` returns to its SDK provider (issue [#6490](https://github.com/go-to-k/cdkd/issues/6490), batch 6)** -- `src/provisioning/provider-registry/sticky-exempt.ts` and the new `cc-to-sdk-reroute-common-types-6` integ. The three types are now `'sdk-coverage'` members of `STICKY_CC_MIGRATION_EXEMPT`, so such a resource on Cloud Control moves to the SDK provider in place on the next deploy that changes it; `--pin-cc-api <LogicalId>` declines that. Both layers record the same id for each (the table bucket ARN, the bare agent runtime id, the evaluator ARN), observed on live resources, so nothing is replaced. `cdkd diff` annotates the move `[returning to SDK provider]`.

- **`AWS::Elasticsearch::Domain` is now refused at pre-flight, and 12 new types route through Cloud Control (PR [#6851](https://github.com/go-to-k/cdkd/pull/6851))** -- `src/provisioning/unsupported-types.generated.ts`, `src/provisioning/stateful-types.ts`, `scripts/gen-ref-segment-coverage.ts`. AWS now reports `AWS::Elasticsearch::Domain` as `NON_PROVISIONABLE` (its registry schema has no handlers, so Cloud Control can no longer create, update or delete it), and cdkd has no SDK provider for it: a deploy naming it now fails at pre-flight instead of mid-deploy. Use `AWS::OpenSearchService::Domain` instead. New Cloud Control-routed types: `AWS::AgentRegistry::Publisher`, `AWS::Cognito::CIMDPolicy`, `AWS::FSx::ClusterPeer`, `AWS::FSx::SnapmirrorPolicy`, `AWS::FSx::SnapmirrorRelationship`, `AWS::FSx::SnapshotPolicy`, `AWS::FSx::StorageVirtualMachinePeer`, `AWS::NetworkManager::Connection`, `AWS::OpenSearchMemory::Space`, `AWS::OpenSearchService::ReplicationPeer`, `AWS::SageMaker::EndpointPolicy` and `AWS::SageMaker::InferenceRouter`. `AWS::OpenSearchMemory::Space` holds the agent events and memories written to it at runtime, so it joins the stateful-replacement guard. `Ref` of an `AWS::Cognito::CIMDPolicy` is the joined `<UserPoolId>|<CIMDPolicyId>` (measured).

- **The API Gateway Method and Cloud Map Service cleanup messages no longer paste their ids raw into the `aws ...` command they suggest, and the Glue skip warning quotes its placeholder (issue [#3136](https://github.com/go-to-k/cdkd/issues/3136), partial)** -- `src/provisioning/providers/apigateway-provider.ts`, `src/provisioning/providers/servicediscovery-provider.ts`, `src/provisioning/providers/glue-provider.ts`; unit tests in `tests/unit/provisioning/apigateway-provider.test.ts`, `tests/unit/provisioning/servicediscovery-provider-service-attributes.test.ts` and `tests/unit/provisioning/providers/glue-provider.test.ts`. The `aws apigateway delete-method` command (template `RestApiId`, `ResourceId`, `HttpMethod`) and both `aws servicediscovery delete-service` commands (the interrupt handle and the cleanup-failure warning) now render through `pasteableAwsCommand`: each value is shell-quoted, and the whole command is replaced by a `[command withheld: ...]` note when a value would not print exactly or the caller's secret masker would change it. The Glue unusable-`CatalogId` skip warning's `--catalog-id <id>` is now `'<id>'`, since a bare `<id>` is two shell redirections. **A clean value renders exactly as before.** Residuals, held by an open PR: `dynamodb-globaltable`, `rds-dbproxy-targetgroup`, `iam-access-key`.

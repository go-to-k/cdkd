- **`Fn::GetAtt` on an `AWS::Lambda::WebFunctionEndpoint`'s whole `RegionalEndpoints` map (`attrRegionalEndpoints`) and on a path through one of its object members (`RegionalEndpoints.<region>.ScalingConfig.MaxEnvironments`, `.ThrottleConfig.RateLimit`, `.RevisionWeights`) resolves again instead of returning the endpoint ARN (issue [#4992](https://github.com/go-to-k/cdkd/issues/4992)).** Since the SDK provider landed in 0.300.0 these logged `Unknown attribute ... returning physical ID`; 0.301.1 (#4978) restored only the scalar members. The provider now also records `RegionalEndpoints` as the nested region -> entry object in CloudFormation casing, as the Cloud Control path did on 0.299.x, leaving out every member AWS did not assign. A record written by 0.300.x or 0.301.x gains it on the next deploy that reaches the `Fn::GetAtt`, through the stale-attribute heal. Source: `src/provisioning/providers/lambda-web-function-endpoint-provider.ts`.

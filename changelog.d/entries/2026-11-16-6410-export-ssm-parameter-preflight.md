- **`cdkd export` now refuses up front, `--dry-run` included, when an SSM parameter a template parameter names does not exist (issue [#6410](https://github.com/go-to-k/cdkd/issues/6410))** -- `src/cli/commands/export/ssm-parameter-preflight.ts`, `src/cli/commands/export/command.ts`. CloudFormation reads every SSM-typed parameter when it creates the IMPORT changeset. Every CDK stack declares `BootstrapVersion`, read from `/cdk-bootstrap/<qualifier>/version`, which only `cdk bootstrap` creates, and `cdkd deploy` never reads it. So a stack deployed without `cdk bootstrap` passed `cdkd export --dry-run` and then failed the real run with CloudFormation's `Unable to fetch parameters`. The export now reads each such parameter before it takes the lock, names the missing ones, and points a CDK bootstrap path at `cdk bootstrap`. A read that fails for any other reason is left to CloudFormation.

- **`cdkd diff` masks a value a consumer stack imports from a producer output derived from a secret-fed nested row (issue [#7090](https://github.com/go-to-k/cdkd/issues/7090))** -- `src/analyzer/cross-stack-preview.ts`, `src/cli/commands/diff-recursive/cross-stack-taint.ts`, `src/cli/commands/diff-recursive/passed-secret-display.ts`, `src/cli/commands/diff-recursive/build-tree.ts`, `src/cli/commands/diff-recursive/compute-stack-diff.ts`, `src/cli/commands/diff.ts`. Since #7068 the producer's own rows showed `***`, but a consumer diffed in the same run that read the output through `Fn::ImportValue` or `Fn::GetStackOutput` still printed the plaintext. This happened in text and in `--json`, at any length, whenever the row record predated masked outputs. The run's cross-stack preview now carries provenance beside each value. Each output (and its export) whose template reads a secret-fed name is marked, whether it changes or not. The marks are made from the app's templates (nested ones included) before any diff, so this also holds when the producer is not diffed in the run. A consumer that reads it, and every resource, output, nested row parameter and child reading that consumer resource, is masked as #7068 masks a passed secret: in the text output, in `--json`, on the `--verbose` replacement line, in the security table, and as print needles over the consumer's resolver lines. Display only: the consumer compares on the real value, so a consumer already holding it stays unchanged. `cdkd deploy` builds no preview, and its side is #7097. When the producer is not diffed, the consumer's own resolver `--verbose` lines remain #7077.

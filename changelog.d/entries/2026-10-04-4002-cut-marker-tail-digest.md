- **A value cut at a display cap now names its withheld tail, so two long values that differ only past the cut no longer print alike (issue [#4002](https://github.com/go-to-k/cdkd/issues/4002))** -- `src/utils/display-safe.ts`, `src/cli/commands/export.ts`. An identifier cdkd cuts at its cap (255 characters, or 1152 for a stack name) was followed by `[cut: N more characters withheld]`, so two planted values sharing the kept prefix and the length rendered byte-identically. The marker now reads `[cut: N more characters withheld, tail sha256:<32 hex>]` for an identifier (a stack name, region, logical id, or a state-record value in `cdkd export`'s plan), the digest taken over the withheld characters only, after any masking. Free-form AWS error text keeps the bare marker. `cutMarker` is now the one spelling of the marker. Tests: `tests/unit/utils/display-safe.test.ts` and the suites that pin the marker.

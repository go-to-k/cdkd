- **A Lambda update that meets an update already in progress is now retried (issue [#6401](https://github.com/go-to-k/cdkd/issues/6401))** -- `src/deployment/retryable-errors/patterns.ts`. When a function's previous update was still `LastUpdateStatus: InProgress` (a console or CLI change, another pipeline, an interrupted deploy), Lambda refused cdkd's `UpdateFunctionConfiguration` / `UpdateFunctionCode` with `ResourceConflictException: ... An update is in progress for resource: <arn>`, and `cdkd deploy` or `cdkd drift --revert` failed on the first attempt. That message is now retried with backoff until the other update settles. A `ResourceConflictException` for a function name that already exists still fails at once.

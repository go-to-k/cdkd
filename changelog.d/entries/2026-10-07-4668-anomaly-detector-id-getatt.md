- **`Fn::GetAtt [<detector>, AnomalyDetectorId]` on `AWS::CloudWatch::AnomalyDetector` now resolves (issue [#4668](https://github.com/go-to-k/cdkd/issues/4668))** -- `src/provisioning/providers/cloudwatch-anomaly-detector-provider.ts`. The registry schema renamed the type's read-only primary identifier from `Id` to `AnomalyDetectorId`. The SDK provider recorded and resolved only `Id`, so `AnomalyDetectorId` fell through to the resolver's unknown-attribute physical-id fallback with a warning, and failed under `--strict-getatt`. Both names are now recorded on create, update and import and accepted by `getAttribute`, with the same value (cdkd's physical id); `Id` stays for aws-cdk-lib releases whose `attrId` still emits it. Tests: `tests/unit/provisioning/providers/cloudwatch-anomaly-detector-provider.test.ts`.

- **An S3 Express directory bucket with `DataRedundancy: SingleLocalZone` now creates with `Location.Type: LocalZone` (issue [#5317](https://github.com/go-to-k/cdkd/issues/5317))** -- `src/provisioning/providers/s3-directory-bucket-provider.ts` always sent `Location.Type: AvailabilityZone`, so a Local Zone directory bucket the template allows was expected to be refused at create. `SingleLocalZone` now sends `LocalZone`; every other value (and an absent one) keeps `AvailabilityZone`. Unit tests only: a real-AWS arm would need a Local Zone opted in on the integ account. `readCurrentState` now reads `DataRedundancy` from `HeadBucket`'s `BucketLocationType`, so a Local Zone bucket does not show a phantom drift.

- **`cdkd drift` on a nested stack no longer resolves a parent-supplied secret reference in the wrong region (issue [#4213](https://github.com/go-to-k/cdkd/issues/4213))** -- `src/cli/commands/drift.ts`. A nested child receives a parent's cross-region value only as a Parameter and records it as the parent's region-less `{{resolve:...}}` expression, but `cdkd drift` classified that expression against the child's own cross-stack reads only, so detection compared against a same-named secret in the stack's region and `--revert` wrote it to the live resource. Drift now unions a nested stack's producer regions with every ancestor's, read from their state records (the #4174 model), for both detection and `--revert`. When an ancestor record cannot be read, every region-less secret reference is refused (`DRIFT_SECRET_REGION_UNKNOWN`) and the resource is reported not compared. Tests: `tests/unit/cli/drift-nested-producer-regions.test.ts`, `tests/unit/cli/drift-cross-region-secret.test.ts`.

- **`AWS::EMR::InstanceGroupConfig` now serves `Fn::GetAtt` on `InstanceGroupId` as well as `Id` (issue [#3632](https://github.com/go-to-k/cdkd/issues/3632))** -- `src/provisioning/providers/emr-instance-group-config-provider.ts`, plus tests. The CFn schema renamed the read-only attribute from `Id` to `InstanceGroupId` ([#3629](https://github.com/go-to-k/cdkd/pull/3629)). Before this change, a template reading the new name, which an aws-cdk-lib regenerated from that schema emits as `attrInstanceGroupId`, got `undefined`. Both names now resolve to the instance group id (the physical id), so templates from older and newer aws-cdk-lib both work.

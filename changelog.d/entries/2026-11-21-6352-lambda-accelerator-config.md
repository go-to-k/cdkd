- **A GPU Lambda function's `AcceleratorConfig` stays on the SDK route** (issue #6352). The `AWS::Lambda::Function` SDK provider did not send `AcceleratorConfig`, so a function declaring it moved to Cloud Control, and stayed there. The provider now sends it on `CreateFunction` and `UpdateFunctionConfiguration`, applies a size change in place, and reads it back from `GetFunction` for drift. Removing it is refused before any call: its one member is required, so no update removes it, and the deploy would otherwise report a change AWS never made. A rollback replay warns instead. `@aws-sdk/client-lambda` moves to 3.1175.0, the first release that models the field. Adds unit coverage and a `lambda-accelerator-config` integration fixture.

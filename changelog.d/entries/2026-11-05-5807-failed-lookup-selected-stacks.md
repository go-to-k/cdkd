- **A failed context lookup blocks `cdkd diff`, `import`, `export`, `publish-assets`, `scrub`, `refactor`, `orphan` and `local invoke` / `run-task` / `start-api` / `invoke-agentcore` only when a stack the command uses asked for it, and no longer blocks `cdkd list` (issue [#5807](https://github.com/go-to-k/cdkd/issues/5807))** -- `src/synthesis/failed-lookups.ts`, `src/cli/commands/*.ts`, `docs/architecture-deploy-pipeline.md`. Before this change, `cdkd diff StackA` failed with `Context lookup failed` when only StackB's lookup failed, while `cdk diff StackA` succeeds. Now the stacks the command selected are checked, as the AWS CDK CLI does; `synth` and `deploy` keep failing through the stack's error annotation.

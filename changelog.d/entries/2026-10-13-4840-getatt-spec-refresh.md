- **`cdkd import` through Cloud Control keeps `ProposedSegmentChange` on NetworkManager attachments (PR [#4840](https://github.com/go-to-k/cdkd/pull/4840))** -- `src/provisioning/getatt-attributes.generated.ts`, regenerated from `@aws-cdk/aws-service-spec` 0.1.219. On `AWS::NetworkManager::ConnectAttachment`, `SiteToSiteVpnAttachment`, `TransitGatewayRouteTableAttachment` and `VpcAttachment`, `ProposedSegmentChange` is both a writable property and a `Fn::GetAtt` attribute. An import recorded it as `***`, so a later deploy reading `Fn::GetAtt <attachment>.ProposedSegmentChange` from the imported resource was refused. It is now kept, like the other writable attributes (#3735).

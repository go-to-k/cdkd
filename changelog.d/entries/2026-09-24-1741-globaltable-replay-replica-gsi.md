- **A rollback that re-creates a DynamoDB GlobalTable whose recorded `GlobalSecondaryIndexes` is malformed no longer sends or records a cross-region replica's override for the index it did not build (issue [#1741](https://github.com/go-to-k/cdkd/issues/1741), second instance)** -- `src/provisioning/providers/dynamodb-globaltable-provider.ts` (new `withdrawReplicaIndexBlocks`), its replay-create unit tests, and an opt-in cross-region arm on `tests/integration/rollback-replay-effective-props` (`CDKD_INTEG_MULTI_REGION=1`). On a reverse-replacement rollback, a state record with a malformed index block is re-created with NO indexes (the #1544 downgrade). Each cross-region replica's `GlobalSecondaryIndexes` override was still sent with the replica-add and kept in the recorded properties. AWS accepted the call, but the re-created replica holds no override, since the index does not exist. So the record described a value `readCurrentState` can never read back, the phantom-drift class of #1724. The omit now withdraws every replica's index block: nothing is sent, the pre-flight scan no longer reports on it, no per-index autoscaling target is requested for it, and it is left out of the recorded properties. A warning names each cross-region replica whose override was withdrawn. The first instance, the orphaned `AttributeDefinitions` prune, shipped earlier.

Each output is now classified from the cloud assembly's templates, never from child state, so the deploy and `cdkd diff` agree: a passed parameter takes the class the parent gives its value, an unpassed one its `Default`, and a `NoEcho` parameter, a `{{resolve:...}}` reference, a cross-stack read, an undeclared name, a custom resource's attribute or a condition over a secret keep the output as written, as does an unreadable or cyclic tree. Grandchild outputs are followed. A clean output is hashed with the value the parent recorded, through the existing secret checks. Values a parent passes from a sibling's clean output are classified clean too. A resource whose own definition reads a nested output is still treated as reading a secret.

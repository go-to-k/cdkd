- **Every command starts about a quarter faster from the second run: cdkd enables Node's compile cache (issue [#4521](https://github.com/go-to-k/cdkd/issues/4521))** -- `src/cli/index.ts`. The entry calls `module.enableCompileCache()` before importing the command tree, so V8 reuses compiled code for cdkd's chunks and the externalised `@aws-sdk/*` packages instead of compiling them on every run (`cdkd --help`: ~890 ms to ~680 ms wall-clock with a warm cache). The cache lives in Node's default `node-compile-cache` directory under the OS temp dir; `NODE_DISABLE_COMPILE_CACHE=1` turns it off and `NODE_COMPILE_CACHE` moves it (CLI Reference, "Startup compile cache"). The `--version` fast path is unchanged. Tests: `tests/unit/cli/version.test.ts`.

- **`cdkd drift` no longer reports an AppSync GraphQL schema without an explicit `schema { query: Query }` block as drifted right after deploy (issue [#6779](https://github.com/go-to-k/cdkd/issues/6779))** -- `src/provisioning/providers/appsync/read-state.ts` (`canonicalizeSdl`), `tests/unit/provisioning/appsync-provider-readcurrentstate.test.ts`, `tests/integration/appsync/`. AWS's `GetIntrospectionSchema` SDL always carries the schema definition, while a CDK schema file usually omits it (legal under the GraphQL spec when the root types use the default names), so the two canonical forms differed and `drift` exited 1 on an untouched stack (and `--revert` re-sent the same schema). The canonicalizer now drops a schema definition with no description or directives whose operations all use `Query` / `Mutation` / `Subscription`; one naming a non-default root type, or carrying directives, is kept so a real change still shows as drift.

- **`cdkd diff --recursive` resolves a consumer's nested-row parameters against this run's cross-stack preview (issue [#7102](https://github.com/go-to-k/cdkd/issues/7102))** -- `src/cli/commands/diff-recursive/child-parameters.ts`, `src/cli/commands/diff-recursive/build-tree.ts`. A nested row parameter `{"Fn::ImportValue": ...}` (or `Fn::GetStackOutput`) of a consumer stack read the producer's STATE, while the consumer's own resources read the value the producer's diff in the same run publishes (#6796). When the producer changed the export, the child previewed the old value. The child-parameter resolution now reads the same preview, as the deploy (which reaches the consumer after the producer saved) passes it. A value the producer publishes only when it deploys leaves the parameter unresolved, as for the consumer's own resources. Its provenance is the row's, so a value derived from a secret is masked on every child leaf at any length, as #7090 masks it.

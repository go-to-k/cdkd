- **The torn `properties` map texts describe a logical id that is not a plain identifier instead of quoting it (issue [#4253](https://github.com/go-to-k/cdkd/issues/4253))** -- `src/state/malformed-resources-bag.ts`; cases in `tests/unit/state/malformed-resources-bag.test.ts`. The `cdkd deploy` refusal, the `cdkd diff` warning, the `cdkd orphan` refusal and the `cdkd drift` refusal and warning named each damaged record by its logical id in JSON quotes, on a message ending in a pasteable `cdkd state show`. A logical id is a key of the state record, and JSON quotes still run a `$( )` or a backtick when that text is pasted into a shell, or when an unpaired `'` or `"` pasted above it flips the quoting. Such an id, and a padded, cut or unrenderable one, now prints as `(not shown: it is not a plain identifier)`, as the `cdkd export` text has since [#4245](https://github.com/go-to-k/cdkd/pull/4245); a plain id is still named. The `cdkd state show` command at the end of each text shows the record's real keys.

- **`cdkd local run-task` refuses a container `Command` / `EntryPoint` / health-check element reading `Fn::GetAtt` of an `AWS::AppSync::ApiKey`'s `ApiKeyId`, as it already refused `ApiKey` (issue [#6238](https://github.com/go-to-k/cdkd/issues/6238))** -- `src/utils/stringify.ts`, `scripts/gen-sdk-attr-coverage.ts`. `ApiKeyId` is CloudFormation's second name for the same `x-api-key` value, but only `ApiKey` was listed as secret-valued, so the key could be resolved onto the `docker run` command line; `cdkd orphan --force` also no longer splices a cached `ApiKeyId`. The SDK attribute-coverage critic now also checks read-only attributes spelled `...ARN` / `...URL` (such as `AutoScalingGroupARN`), which the deploy-time guard lets fall back to the physical id. The five `Fn::GetAtt` values the issue reported already match CloudFormation on `main` (#6273, #6278, #6304). Tests: `tests/unit/local/ecs-task-resolver-command-intrinsics.test.ts`, `tests/unit/analyzer/orphan-rewriter.test.ts`, `tests/unit/scripts/gen-sdk-attr-coverage.test.ts`.

- **A Docker image asset now publishes when docker's credential store holds an expired ECR token (issue [#5747](https://github.com/go-to-k/cdkd/issues/5747))** -- `src/assets/docker-asset-publisher.ts` and its unit tests. ECR answers a push made with an expired cached token with `Your authorization token has expired`. cdkd did not count that as an authentication failure, so it skipped its log-in-and-retry and the deploy failed until the user logged in to ECR by hand. cdkd now logs in and retries the push once, as it already did for a missing credential. The same retry now also covers an `is not authorized to perform` denial: docker's containerd image store drops the `denied:` prefix that the classic store kept, so a denial for a token cached by another principal was missed there too.

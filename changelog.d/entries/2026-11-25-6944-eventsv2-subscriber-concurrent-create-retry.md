- **A create refused as a concurrent modification by EventBridge is retried, so several `AWS::EventsV2::Subscriber` resources on one event bus can be created in one deploy (issue [#6944](https://github.com/go-to-k/cdkd/issues/6944))** -- `src/deployment/retryable-errors/patterns.ts`, `tests/unit/deployment/retryable-errors.test.ts`. cdkd creates sibling Subscribers in parallel, and EventBridge can refuse a create that overlaps another one on the same bus with HTTP 409 `This resource was modified concurrently. Please retry your request.`. The message matched no retryable pattern, so the refused create was not retried: on v0.368.1, 4 of 4 deploys of six Subscribers on one bus failed, on a different subset each run, while one deploy of the same six created serially succeeded. `This resource was modified concurrently` is now matched as a substring by the retryable transient patterns, on the exponential cadence. With it, 3 of 3 live deploys succeeded, logging 1, 2 and 6 matching retry lines, and each destroy reported `10 deleted, 0 errors`. The 409 for deleting a bus that still has Subscribers does not contain the sentence and stays unmatched.

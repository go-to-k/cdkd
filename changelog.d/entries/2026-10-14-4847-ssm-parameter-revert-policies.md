- **`cdkd drift --revert` of an `AWS::SSM::Parameter` no longer fails with "Start of list found where not expected"** -- `src/provisioning/providers/ssm-parameter-provider.ts`. The read-back baseline drift reverts from holds the parameter's policies as a parsed list (an empty one when it has none), and the update sent that list to `PutParameter`, which takes a JSON string, so AWS refused every revert of an SSM parameter. A list is now sent as its JSON string, and the empty placeholder as no `Policies`, as an absent template property is. Found by the `rollback-cross-region-secret` integ of issue [#4847](https://github.com/go-to-k/cdkd/issues/4847).

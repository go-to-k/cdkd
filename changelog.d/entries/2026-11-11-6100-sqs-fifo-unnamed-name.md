- **An un-named FIFO SQS queue now deploys (issue [#6100](https://github.com/go-to-k/cdkd/issues/6100))** -- `src/provisioning/resource-name/fallback-rules.ts`, `src/provisioning/resource-name/fallback.ts` and `src/provisioning/providers/sqs-queue-provider.ts`, plus a new `sqs-fifo-unnamed` integ. Before, `new sqs.Queue(this, 'Q', { fifo: true })`, which synthesizes `FifoQueue: true` and no `QueueName`, failed to deploy with `InvalidParameterValue`: cdkd sent its standard generated name, and SQS refuses a FIFO queue whose name does not end with `.fifo`. A replacement onto such a queue failed the same way. Like CloudFormation, cdkd now ends the generated name of a FIFO queue with `.fifo`, counted within the 80-character limit and kept when a long name is truncated. `FifoQueue` given as the string `'true'` counts too. The name-collision lookup, the Cloud Control route and the replacement-name checks derive the same name as the create.

- **`cdkd drift` reports a Bedrock AgentCore runtime's hooks, resource, filesystem or request-header configuration added outside cdkd, and `--revert` clears it (issue [#6651](https://github.com/go-to-k/cdkd/issues/6651))**. Drift skips every key the template does not declare whose recorded value is empty (`[]`, `{}`, `null`), because another resource or AWS fills many such keys after the deploy (issue [#1498](https://github.com/go-to-k/cdkd/issues/1498)). That skip also hid an out-of-band add to a key nothing else writes. A new per-type table, `UNDECLARED_EMPTY_COMPARED_KEYS`, lists keys compared even when recorded empty; a key joins it only by measurement. It starts with `AWS::BedrockAgentCore::Runtime` `HooksConfiguration`, `ResourceConfigurations`, `FilesystemConfigurations` and `RequestHeaderConfiguration` (measured us-east-1: all four reported, reverted and cleared on AWS). Reverting any runtime without a `Description` also failed, because the revert sent the read's `''` placeholder, which `UpdateAgentRuntime` refuses (length >= 1); the update now leaves `''` out, which clears the description.

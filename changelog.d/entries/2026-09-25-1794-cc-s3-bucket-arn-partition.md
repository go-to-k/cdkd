- **A Cloud Control-routed S3 bucket records its `Arn` in the right partition (issue [#1794](https://github.com/go-to-k/cdkd/issues/1794))** -- `src/provisioning/cloud-control-provider.ts`, its unit tests. When Cloud Control did not report an `AWS::S3::Bucket` `Arn`, cdkd filled it in as `arn:aws:s3:::<bucket>` in every region, so a CC-routed bucket in `aws-cn` or `aws-us-gov` recorded (and served to `Fn::GetAtt`) a commercial ARN that no policy in that partition matches, while the SDK-routed bucket already recorded the real partition. The fallback now derives the partition from the Cloud Control client's region through the same builder the SDK provider uses, so both routes record the same value. Commercial-region output is unchanged.

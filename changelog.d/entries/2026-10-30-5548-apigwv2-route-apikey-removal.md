- **Removing `ApiKeyRequired` from an `AWS::ApiGatewayV2::Route` now keeps API key enforcement on, as CloudFormation does (issue [#5548](https://github.com/go-to-k/cdkd/issues/5548), part of [#1160](https://github.com/go-to-k/cdkd/issues/1160))** -- `src/provisioning/providers/apigatewayv2-provider.ts` (`updateRoute`, `removalHandledInUpdate`); unit tests in `tests/unit/provisioning/apigatewayv2-stage-route-props.test.ts`. A redeploy that dropped `ApiKeyRequired: true` from a WebSocket route used to send `ApiKeyRequired: false`, so the route started accepting calls without an API key. Measured against CloudFormation, the removal keeps `true`, both alone and beside another change to the same route, and the value still reads `true` minutes later. cdkd now sends nothing for the removal. Every Route property is also declared in `removalHandledInUpdate`, since each removal is already measured.

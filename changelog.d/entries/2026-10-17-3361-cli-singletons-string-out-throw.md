- **A failure that cannot be converted to text no longer turns a best-effort handler in `cdkd export`, `cdkd import`, `cdkd local start-api`, `cdkd orphan`, asset publishing or config loading into a hard failure** (`src/cli/commands/{export,import,local-start-api}.ts`, `src/analyzer/orphan-rewriter.ts`, `src/assets/docker-asset-publisher.ts`, `src/cli/{config-loader,upload-cfn-template}.ts`, `src/synthesis/context-store.ts`, go-to-k/cdkd#3361). These handlers built their message with `x instanceof Error ? x.message : String(x)` (or a bare `String(x)`), and `String()` throws for a null-prototype object, so the handler itself threw: an unreadable `cdk.json` / `cdk.context.json` failed the command instead of warning; a failed DescribeType skipped `cdkd export`'s fallback identifier table; a provider lookup failure aborted the orphan reference rewrite instead of reporting the reference as unresolvable; a failed watcher close or tmpdir removal in `local start-api`'s shutdown skipped the cleanup after it, the profile-credentials tmpdir removal among them, and a failed `--warm` pre-warm stopped the server from starting; `cdkd export`'s lock release, template-upload cleanup and per-stack state removal stopped the run; and a docker push rejection was replaced by a `TypeError` before the ECR auth retry could classify it. The transient-template version purge (`upload-cfn-template.ts`), which nothing known today makes reject, is converted as defence in depth. Each now goes through `describeAwsFailure(x).detail` (or `safeStringify(x)` for the bare form), byte-identical whenever the value converts and a placeholder only when it cannot. Tests: `tests/unit/cli/singletons-string-outthrow-3361.test.ts`.

- **`Fn::GetAtt` of an AutoScaling group's `AutoScalingGroupARN` and an EventBridge rule's `RuleName` now returns the value CloudFormation returns (issue [#6242](https://github.com/go-to-k/cdkd/issues/6242), second slice)** -- `src/deployment/intrinsic-resolver/getatt-construct-app.ts`, unit tests and a new `getatt-asg-arn-rule-name` integ fixture. Before, `AutoScalingGroupARN` resolved to the group name (its upper-case `ARN` suffix slipped past the guard that refuses a non-ARN `*Arn` value) and `RuleName` to the whole rule ARN, each with only an `Unknown attribute` warning. Now `AutoScalingGroupARN` is the ARN cdkd already records for the group (a group whose record lacks it fails the deploy instead of becoming the name), and `RuleName` is the plain rule name, also for a rule on a custom event bus, as measured against CloudFormation.

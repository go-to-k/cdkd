- **A failure value that cannot be converted to text no longer replaces the outcome of the ACM certificate replacement, the Cloud Map partial-create cleanup, the Cognito remove-protection fallback or the Lambda create failure** (`src/provisioning/providers/{acm-certificate,servicediscovery,cognito,lambda-function}-provider.ts`, go-to-k/cdkd#3361). These helpers took the caught value as a PARAMETER, where the catch-scoped sweep did not look, and rendered it with `String()`, which throws for a null-prototype object. So a `TypeError: Cannot convert object to primitive value` failed an ACM update whose new certificate already existed (it now reports `partial`, as for any other old-certificate delete failure), replaced the ServiceAttributes failure a Cloud Map create rethrows, replaced the delete's own refusal when Cognito's settings echo failed with such a `name`, and replaced the Lambda create failure. Each now goes through `describeAwsFailure(x).detail` or `safeStringify(x)`, byte-identical for every value `String()` converts and a placeholder otherwise.

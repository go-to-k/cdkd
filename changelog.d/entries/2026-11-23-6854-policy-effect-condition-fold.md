- **A policy document written with a lowercase `Effect` or a numeric / boolean condition value now matches what S3 stores (issue [#6854](https://github.com/go-to-k/cdkd/issues/6854))** -- `src/provisioning/policy-document-content.ts`, `tests/unit/provisioning/policy-document-content-4612.test.ts`. S3 stores `"Effect": "allow"` as `"Allow"` and returns a condition value `1.2` (CDK's `minimumTLSVersion`) as `"1.2"` and `false` as `"false"`. The policy comparison treated each pair as different, so an S3 bucket policy create retried after a crash refused its own leftover as one that already exists, and a declared policy in those forms could read as drift. Both pairs now compare equal; `1.2` still differs from `"1.20"`.

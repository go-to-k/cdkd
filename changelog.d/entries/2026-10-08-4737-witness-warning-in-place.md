- **A deploy no longer warns that a resource "is replaced" when a changed NoEcho value on a schema create-only property is updated in place (issue [#4737](https://github.com/go-to-k/cdkd/issues/4737))** -- `src/deployment/deploy-engine/update.ts`. Where a record held a plaintext at a position a `NoEcho` parameter now feeds (a pre-v11 record, or a literal turned into a `{Ref}` to the parameter) and the value differs, the deploy printed `<id>.<prop> is a create-only property, and a NoEcho parameter's value changed since the last deploy: <id> is replaced.` for every property the CloudFormation schema lists as create-only. For one cdkd updates in place (an `AWS::Budgets::Budget`'s `NotificationsWithSubscribers`, which its provider reconciles), the deploy sent an in-place update and printed that line anyway. The line is now printed only when the change replaces the resource. Tests: `tests/unit/deployment/deploy-engine-noecho-v11.test.ts`.

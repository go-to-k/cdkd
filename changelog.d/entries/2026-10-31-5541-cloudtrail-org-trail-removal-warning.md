- **CloudTrail Trail: a removed `IsOrganizationTrail` is now named in a warning (issue [#5541](https://github.com/go-to-k/cdkd/issues/5541))** -- `src/provisioning/providers/cloudtrail-provider.ts`. Removing `IsOrganizationTrail: true` from the template sends nothing to `UpdateTrail`, so the trail stays an organization trail. Before this change cdkd said nothing; now one warning per resource names the property as left at its current AWS value and says CloudFormation's behaviour for the removal is unmeasured (the A/B needs an AWS Organizations management or delegated-administrator account). The same warning names `IncludeGlobalServiceEvents` when its removal reset is skipped because the trail is, or may be, multi-region. The type now declares `removalHandledInUpdate`, so the deploy's shared removal warning, which says CloudFormation would reset the value, names no Trail property. Tests: `tests/unit/provisioning/cloudtrail-trail-removal-kept-5541.test.ts`.

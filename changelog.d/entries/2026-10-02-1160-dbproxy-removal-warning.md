- **Removing an optional setting from an RDS DB proxy now warns that the live value is kept, instead of passing silently (issue [#1160](https://github.com/go-to-k/cdkd/issues/1160))** -- `src/provisioning/providers/rds-dbproxy-provider.ts`. Dropping `Auth`, `RequireTLS`, `IdleClientTimeout`, `DebugLogging` or `VpcSecurityGroupIds` from an `AWS::RDS::DBProxy` reported a successful update while the proxy kept its old value, because `ModifyDBProxy` keeps any setting it is not sent. cdkd still sends no reset, since CloudFormation's published DBProxy handler forwards the same omission, but the update now prints one warning naming each removed property and how to change it (a rollback revert words it as the state being restored), and a removal alone no longer issues an empty `ModifyDBProxy` call. `cdkd drift --revert` warns about nothing. Tests: `tests/unit/provisioning/rds-dbproxy-provider.test.ts`.

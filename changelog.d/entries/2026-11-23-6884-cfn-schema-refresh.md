- **`AWS::WAFv2::WebACL` keeps the SDK route for the new `AnalyticsConfig` property (PR [#6884](https://github.com/go-to-k/cdkd/pull/6884)).** The 2026-11-23 schema refresh carries `AnalyticsConfig` (`Mode: CROSS_REGION | DISABLED`, security analytics). It now rides on `CreateWebACL` and `UpdateWebACL` and is read back from `GetWebACL` for `cdkd drift`, so a web ACL declaring it does not move to Cloud Control. Removing it from the template resets the web ACL to AWS's default for its scope (disabled for a regional web ACL, enabled for a CloudFront one), because an `UpdateWebACL` that leaves it out resets the stored mode; declare `Mode: DISABLED` to keep a CloudFront web ACL's request logs in-Region. A web ACL that never set it reports no drift. `@aws-sdk/client-wafv2` is raised to 3.1175.0, the first version that models the member. Source: `src/provisioning/providers/wafv2/`.

- **`cdkd diff` no longer previews a literal `Export.Name` alias the deploy refuses, in a stack whose recorded secret is not spelled in an output value (issue [#4143](https://github.com/go-to-k/cdkd/issues/4143))** -- `src/analyzer/outputs-diff.ts`, `src/deployment/outputs-export-alias.ts`. The preview decides a literal alias from state only when the deploy's outputs pass records a secret. That gate read only output values spelling `secretsmanager` / `ssm-secure`, so it missed a plain-`ssm` SecureString (which keeps its token through the preview's resolution) and a `secretsmanager` reference spelled only in an intrinsic `Export.Name`. The preview published the alias as a phantom `[export]` ADD on every run. The gate now also counts a resolved output value or intrinsic name that keeps a secret token, so literal aliases are decided after every output has resolved. Tests: `tests/unit/analyzer/outputs-diff-ssm-export-name-4056.test.ts`, `tests/unit/analyzer/outputs-diff.test.ts`, `tests/unit/deployment/deploy-engine-outputs-export-name-collision.test.ts`.

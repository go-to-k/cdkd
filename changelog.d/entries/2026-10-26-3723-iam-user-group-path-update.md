- **A changed `Path` on an `AWS::IAM::User` or `AWS::IAM::Group` is now applied on update (issue [#3723](https://github.com/go-to-k/cdkd/issues/3723))** -- `src/provisioning/providers/iam-user-group-provider.ts`. The property is mutable in place (CloudFormation applies it with `UpdateUser` / `UpdateGroup` `NewPath`), but `update()` never sent it: a deploy that changed or removed the Path succeeded while the user or group stayed under the old path, its ARN unchanged and the state record disagreeing with IAM. `update()` now moves the principal when the declared path differs from the recorded one, an absent Path reading as IAM's default `/`, and returns the ARN read after the move. Found by the SDK wire harness (`tests/unit/provisioning/sdk-wire-cases-3.ts`); unit cases in `tests/unit/provisioning/iam-user-group-provider-path-update.test.ts`.

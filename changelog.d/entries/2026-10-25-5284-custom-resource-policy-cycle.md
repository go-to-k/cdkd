- **A stack of `AwsCustomResource` constructs chained with `DependsOn` no longer fails with `Circular dependency detected` (issue [#5284](https://github.com/go-to-k/cdkd/issues/5284))** -- `src/analyzer/dag-builder.ts`. `addCustomResourcePolicyEdges` adds an edge from every IAM policy on a custom resource's handler role to every custom resource using that handler. `AwsCustomResource` shares one handler between all instances and gives each its own policy, so for a chain the rule made the first instance wait for the last one's policy, which waits for the first: a cycle that is not in the template and that CloudFormation never builds. The edge is now skipped when the custom resource already reaches the policy, so each instance still waits for its own policy and every policy that is not downstream of it. A cycle that is in the template itself still throws. Unit cases in `tests/unit/analyzer/dag-builder.test.ts` (five fail without the fix). All 201 real templates of a production-sized app build, and the stack that failed deployed and destroyed cleanly.

- **`AWS::RDS::DBProxyEndpoint` keeps the SDK route for `EndpointNetworkType` (issue [#2762](https://github.com/go-to-k/cdkd/issues/2762)).** An endpoint declaring it used to go through Cloud Control. It is now sent on `CreateDBProxyEndpoint` and read back for `cdkd drift`; a change replaces the endpoint, as CloudFormation does for this create-only property. Source: `src/provisioning/providers/rds-dbproxy-endpoint-provider.ts`.

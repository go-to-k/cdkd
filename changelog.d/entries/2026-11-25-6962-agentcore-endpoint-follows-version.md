- **A Bedrock AgentCore runtime endpoint now follows the runtime's new version after an update, as CloudFormation does (issue [#6962](https://github.com/go-to-k/cdkd/issues/6962))** -- `src/analyzer/diff-calculator/shared.ts`. Every runtime update mints a new version, but `AgentRuntimeVersion` is not a template property, so an endpoint reading it (CDK `addEndpoint()`) diffed unchanged and stayed on the old version, in every mode. The runtime's `AgentRuntimeVersion` now counts as moved by its in-place updates, so the endpoint is updated to the new version. Tests: `tests/unit/deployment/deploy-engine-agentcore-endpoint-version-6962.test.ts`.

- **`cdkd rollback`, `cdkd events`, the SSM parameter import refusal and the Cloud Control import identifier messages no longer wrap a stack name, region, run id or physical id in cdkd's own `'...'` (issue [#3950](https://github.com/go-to-k/cdkd/issues/3950), partial)** -- `src/cli/commands/rollback.ts`, `src/cli/commands/events.ts`, `src/provisioning/cc-import-identifier.ts`, `src/provisioning/providers/ssm-parameter-provider.ts`, with paste cases in `tests/unit/cli/commands/rollback.test.ts`, `tests/unit/cli/events-display-safe.test.ts`, `tests/unit/provisioning/cc-import-identifier.test.ts` and `tests/unit/provisioning/pasteable-command-hand-quoted-ids.test.ts`, and a `src/**` fence in `tests/unit/utils/record-value-prose-quotes-fence.test.ts`. A value carrying `'` closed that quote, so pasting the sentence ran what followed it as shell. The value now carries its own boundary: a plain one prints bare (`Roll back MyStack (us-east-1)?` instead of `Roll back 'MyStack' (us-east-1)?`) and any other JSON-quoted. `cdkd events`' multiple-regions error ends in a `--stack-region` remedy, so it describes a stack name or region that is not a plain identifier rather than printing it, and then points at a read-only S3 key listing, and the Cloud Control `--resource` remedy prints a `<logicalId>` placeholder for such a logical id. The `export.ts`, `state.ts`, `cdkd local`, `intrinsic-function-resolver.ts`, `composite-id.ts` and `scheduler-schedule-provider.ts` sites, and the double-quoted ones in `options.ts` and `replacement-name-holder.ts`, stay open on #3950.

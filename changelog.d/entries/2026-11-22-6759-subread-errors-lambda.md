- **`cdkd drift` reports a Lambda function not compared when one of its setting reads fails, instead of leaving the setting out (issue [#6759](https://github.com/go-to-k/cdkd/issues/6759), part of [#6696](https://github.com/go-to-k/cdkd/issues/6696))** -- `src/provisioning/providers/lambda-function/read-state.ts`, `tests/unit/provisioning/providers/lambda-subread-errors-6759.test.ts`. The function readback reads `RecursiveLoop`, `ReservedConcurrentExecutions`, `FunctionScalingConfig`, `RuntimeManagementConfig` and `CodeSigningConfigArn` with their own calls, and it caught any failure of those calls and left the setting out. An `AccessDenied` or a throttle therefore left the setting uncompared, or `cdkd drift` reported it as removed. Now only an answer that says the setting is absent still leaves it out: not set (`ResourceNotFoundException`, or `CodeSigningConfigNotFoundException` for code signing), or not supported by this function (`InvalidParameterValueException`). Any other failure fails the read, and `cdkd drift` reports the function `not compared` (exit 2) with the AWS error.

- **A JWT `AWS::ApiGateway::Authorizer`'s `JwtConfiguration` is now sent by the SDK provider (PR [#6690](https://github.com/go-to-k/cdkd/pull/6690))** -- `src/provisioning/providers/apigateway/jwt-configuration.ts` (new), `authorizer.ts`, `read-state.ts`; `@aws-sdk/client-api-gateway` raised to `^3.1172.0` (3.1171.0 is the first release that models it). The 2026-11-20 schema refresh added the property, which no SDK provider wrote, so a template carrying it routed the authorizer through Cloud Control. CreateAuthorizer now sends it, an update replaces it whole (`replace /jwtConfiguration`, the only form API Gateway accepts), and `cdkd drift` reads it back without the read-only `jwksUri`. A removed `JwtConfiguration` sends nothing: API Gateway refuses to remove it and drops it itself when `Type` leaves `JWT`. Integ: `sdk-unmodelled-nested-route`.

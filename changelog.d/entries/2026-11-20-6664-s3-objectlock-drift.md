- **`cdkd drift` no longer reports a declared `ObjectLockEnabled` as drift on an S3 bucket with no observed baseline (issue [#6664](https://github.com/go-to-k/cdkd/issues/6664))**. The top-level `ObjectLockEnabled` is create-time only and the bucket readback never emits it (the live lock state is read into `ObjectLockConfiguration.ObjectLockEnabled`), so a bucket whose deploy captured no baseline (the capture right after `CreateBucket` can see a 404) showed `- ObjectLockEnabled: true / + ObjectLockEnabled: undefined` forever, exited 1, and `--revert` could not clear it. The key is now listed in the S3 bucket provider's `getDriftUnknownPaths`. Drift-only: no new AWS call.

- **A failed CloudFront Distribution, API Gateway Account or Scheduler Schedule delete whose AWS failure is a `*NotFound` about something else no longer reads the resource as already deleted (issue [#5222](https://github.com/go-to-k/cdkd/issues/5222))** -- `src/provisioning/providers/cloudfront-distribution-provider.ts`, `apigateway-provider.ts`, `scheduler-schedule-provider.ts`, and unit cases. Since thrown messages name an AWS failure by its class (issue #2319), a class such as CloudFront's `EntityNotFound`, `NoSuch*` or `*DoesNotExist` (the disable step's referenced policy, function or key group is gone), API Gateway's `NotFoundException` from `UpdateAccount`, or Scheduler's `ResourceNotFoundException` from the redacted-GroupName `ListSchedules` search satisfied the "already deleted" substring checks, so a live resource's state record could be dropped, or a replacement created beside it. These wraps are now marked non-retryable, which those checks read first. Cloud Control's `RequestTokenNotFoundException` was already safe: it surfaces as an abandoned wait, which every such check refuses.

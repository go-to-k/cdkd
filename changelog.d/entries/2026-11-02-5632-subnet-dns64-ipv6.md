- **Subnet DNS64 and IPv6 CIDR use the SDK route** (Refs #5632). `EC2Provider` passes `Ipv6CidrBlock` at creation and applies `EnableDns64` afterwards. Creation waits for the IPv6 association before DNS64 wiring and observed-state capture. Updates disable DNS64 before changing IPv6 and enable it afterwards. IPv6 comparisons use canonical network forms without rewriting requests, so spelling-only changes do not detach a live block. Updates change the IPv6 association in place; removing its property disassociates it. Removing `EnableDns64` preserves the live value, matching measured CloudFormation behavior. Drift readback includes DNS64 and the associated IPv6 block. Adds unit coverage and an `ec2-subnet-dns64` integration fixture for live values, SDK routing and both removal behaviors.

- **Removing `TracingConfig`, `ContentBasedDeduplication` or `ArchivePolicy` from an SNS topic no longer fails the deploy (issue [#6226](https://github.com/go-to-k/cdkd/issues/6226))** -- `src/provisioning/providers/sns-topic/update.ts`, unit tests and a new `sns-topic-attr-removal` integ fixture. Before, cdkd reset a removed attribute to an empty string, which SNS refuses for these three, so the update failed with `InvalidParameterException` after the attributes ordered before it had already changed. Now a removal resets them the way CloudFormation does: `TracingConfig` to `PassThrough`, `ContentBasedDeduplication` to `false`, and `ArchivePolicy` to no archive policy. `cdkd drift --revert` of an unset `TracingConfig` sends `PassThrough` for the same reason. Removing `SignatureVersion` or `FifoThroughputScope` still fails, as it does in CloudFormation.

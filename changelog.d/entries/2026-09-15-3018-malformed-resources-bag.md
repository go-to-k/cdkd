- **`cdkd diff`, `import`, `orphan` and `scrub` no longer abort on a malformed `resources` bag** — a hand-edited or truncated `state.json` whose resource map is absent or `null` used to kill each of those commands with a bare `TypeError: Cannot convert undefined or null to object`, naming no stack, no key and no remedy, from exactly the commands a user reaches for WHEN the state is broken. Each now repairs the bag to `{}` once at the point it LOADS the record and warns that its output describes an empty resource set — with the record to inspect and the explicit instruction not to run `deploy` or `destroy` against it, both of which would read the same empty map as "nothing is deployed". `deploy` and `destroy` themselves are deliberately unchanged: for them an unreadable bag must stay fatal. Issue #3018.

- **A provider's own log lines now mask the resource's resolved secrets at the logger itself (issue [#2177](https://github.com/go-to-k/cdkd/issues/2177))** -- `src/utils/logger.ts`, `src/utils/log-line-masker.ts`, `src/deployment/resource-secrets-scope.ts`. A provider's `debug` / `info` / `warn` / `error` line reached no engine masking, so a `{{resolve:...}}` secret (or a `NoEcho` parameter value) it interpolated printed in plaintext unless that one call site threaded the masker, and about 256 such sites had not. `ConsoleLogger` now masks every line emitted during a provider create or update with that resource's secret bag, on the live terminal and in the per-stack output buffer of a multi-stack deploy alike. The message is masked before terminal sanitizing, and each string inside an extra log argument before it is JSON-escaped. Lines outside a provider call, and every command that binds no bag, are unchanged and pay one async-context read. Not covered here: names a provider derives from a secret (still masked per site), and `delete()` paths, which bind no bag ([#2007](https://github.com/go-to-k/cdkd/issues/2007)). Tests: `tests/unit/utils/logger-sink-secret-mask.test.ts`.

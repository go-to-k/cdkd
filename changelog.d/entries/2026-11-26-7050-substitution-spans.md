- **A secret referenced inside an intrinsic is never stored in plaintext beside a parameter, an attribute or another value holding its text: the leaf keeps each reference where the resolver substituted it, or is stored masked (issues [#7050](https://github.com/go-to-k/cdkd/issues/7050), [#7059](https://github.com/go-to-k/cdkd/issues/7059))** -- `src/deployment/secret-redaction/redact-path/substitution-spans.ts` (new), `consumed-references.ts` (new), `redact-path/literal-rendering.ts`, `redact-path.ts`, `nested-stack/*`, `src/deployment/intrinsic-function-resolver.ts`, `src/analyzer/diff-calculator/redaction-masks.ts` (new), `src/deployment/masked-property-fingerprints/public-references.ts` (new). A 1-3 character secret (`pg`) beside a value holding its text was stored as `pgpg`. A reference reached through `Fn::Select` / `Fn::Split` was stored in plaintext too, and so was a nested child's read of such a parameter. A leaf the resolver cannot account for by its spans is stored as `***`: a reference consumed without a recorded span, or a parameter or attribute value holding a secret's text. A nested child's read of such a parameter is masked as well. An unchanged template does not plan a masked leaf as a change (the masked-property fingerprints prove it unchanged). A changed public `ssm` value inside one is planned and sent; a secret's is not, as in CloudFormation. A nested child's masked leaf reading a parameter its parent passed as a secret is compared by keyed KMS MACs, else unchanged and warned of; `cdkd diff` shows it as a change. A masked leaf blocks what any masked value blocks (a rollback replay, an export).

- **`--aws-emulator` no longer sets a resource policy holding only the `enforceSSL` `Deny` (issue [#6636](https://github.com/go-to-k/cdkd/issues/6636))** -- `src/provisioning/emulator-secure-transport.ts`, `src/provisioning/providers/{sqs-queue,s3-bucket,sns-topic}-policy-provider.ts`, unit tests and `docs/aws-emulator.md`. The #6574 fix sent such a document unchanged, since dropping the statement left none, and on AWS Emulator it denied every request: an SQS -> Lambda event source mapping on a queue with only `enforceSSL: true` could not be created. Under `--aws-emulator` the queue policy is now cleared (`Policy: ''`), the topic gets its default policy, and the bucket policy is not put on create and deleted on update. Deploys to AWS are unchanged; the state record keeps the templated policy.

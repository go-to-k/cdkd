- **A reader of an unchanged resource whose secret-derived name is assembled by an intrinsic or read from another stack in the same region is no longer sent the unresolved `{{resolve:...}}` spelling (issue [#4805](https://github.com/go-to-k/cdkd/issues/4805))** -- `src/deployment/intrinsic-resolver/getatt.ts` (`referencesRegionProven`), `src/deployment/intrinsic-resolver/context.ts`, `src/deployment/deploy-engine/resolver-context.ts`, `src/deployment/deploy-engine.ts`, `src/deployment/deploy-engine/deploy-flow.ts`. Since go-to-k/cdkd#4800 a reference in a stored record (an SQS `Arn` around a queue named from a secret) is resolved before a reader's `Fn::GetAtt` / `Ref` is served, but only when the resource's template spelled the token literally and read no other stack. A name built by `Fn::Join` / `Fn::Sub` (CDK's `secretValueFromJson` on a secret in the stack), a literal name beside an imported dead-letter queue, a name read by `Fn::ImportValue`, or one copied by `Fn::GetAtt` from another resource was still served as stored: an `AWS::SSM::Parameter` reader refused it and the deploy failed. `cdkd deploy` now also proves the region from the stack's cross-stack reads (its state's `imports` / `outputReads`, this run's reads and a nested child's ancestors'): when they are complete and name no producer in another region, the reference is resolved here. A stack that reads a stack in another region, or a nested child whose parent's reads are unknown, is served as before. The physical-id check of go-to-k/cdkd#4800 still applies, so a rotated secret or a value that is not the name is still served as stored, with a warning.

- **`--aws-emulator` before a required target now prints the flag-placement remedy instead of `missing required argument` (issue [#6382](https://github.com/go-to-k/cdkd/issues/6382))** -- `src/cli/aws-emulator.ts`. The URL is optional, so `cdkd local invoke --aws-emulator MyStack/Handler` reads the target as the URL. The value was checked only after commander had checked the command's arguments, so every command with a required target (`local invoke`, `local run-task`, `state show`, `state resources`, `state orphan`, `events prune`, `orphan`) reported only commander's `error: missing required argument`, although the user had typed it. The value is now checked as the flag is parsed, so these commands refuse with the same message as the others: put `--aws-emulator` after the target, or write `--aws-emulator=<url>`.

- **`AWS::RDS::DBCluster`: `DBSystemId` and `WithExpressConfiguration` are now unhandled by design (issue [#5639](https://github.com/go-to-k/cdkd/issues/5639))** -- `src/provisioning/providers/rds-provider.ts`. Both stay on the Cloud Control route, as before; only the reason `cdkd` reports for the route changes from "not yet implemented" to why neither is wired. The CloudFormation schema documents `DBSystemId` as "Reserved for future use.", so there is no behaviour to wire. CloudFormation's RDS handler cannot create a cluster with `WithExpressConfiguration` today (an RDS 500, `CREATE_FAILED`, measured on 2026-11-07), Cloud Control calls the same handler, so it is expected to fail the same way (inferred, not measured), and there is no reference behaviour to match; issue [#5984](https://github.com/go-to-k/cdkd/issues/5984) tracks re-measuring it.

- **`cdkd drift` now compares an API Gateway method's request settings, an API Gateway stage's tags and an EFS access point's tags (issue [#6696](https://github.com/go-to-k/cdkd/issues/6696))** -- `src/provisioning/providers/apigateway/read-state.ts`, `src/provisioning/providers/efs/read-state.ts`. The readbacks never returned `ApiKeyRequired`, `OperationName`, `RequestValidatorId`, `RequestParameters` and `RequestModels` of an `AWS::ApiGateway::Method`, `Tags` of an `AWS::ApiGateway::Stage`, or `AccessPointTags` of an `AWS::EFS::AccessPoint`. The deploy-time drift baseline is captured through the same readback, so an out-of-band change to any of them reported no drift. A baseline captured before this release lacks them, so they are compared once it is recaptured: an update of the resource, or `cdkd state refresh-observed` (which takes what AWS holds now as the baseline). A new CI check (`scripts/gen-drift-readback-coverage.ts`, `docs/_generated/drift-readback-coverage.md`) fails on a handled property a readback never returns; the gaps it found are tracked in #6754, #6755, #6756, #6757 and #6758.

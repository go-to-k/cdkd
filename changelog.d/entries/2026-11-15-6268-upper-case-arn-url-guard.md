- **`Fn::GetAtt` refuses an upper-case `*ARN` / `*URL` attribute it cannot answer instead of substituting the physical ID, and `cdkd import` adopts Auto Scaling groups (issue [#6268](https://github.com/go-to-k/cdkd/issues/6268))** -- `src/deployment/intrinsic-resolver/getatt-refusals.ts`, `src/provisioning/providers/asg-provider.ts`, `src/provisioning/providers/asg/read-state.ts`, `docs/import.md`. The physical-ID fallback's shape guard refused only names ending `Arn` / `Url`, so an attribute CloudFormation spells `AutoScalingGroupARN`, `ResourceARN`, `ProviderURL` or `EndpointURL` with nothing recorded and a name or id physical ID resolved to that name with only a warning, a wrong value under a green deploy. It is now refused like `*Arn` / `*Url`; a physical ID that is already an ARN or http(s) URL still resolves. `ASGProvider` gains `import()`: `cdkd import` finds a group by `--resource` or the template's `AutoScalingGroupName` (it was listed as not importable), and a state record lacking the group ARN re-reads it from AWS, so `Fn::GetAtt AutoScalingGroupARN` resolves without an unrelated update to the group.

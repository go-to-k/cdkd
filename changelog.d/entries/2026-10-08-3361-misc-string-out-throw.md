- **A failure value that cannot be converted to text no longer turns a best-effort fallback in the analyzer, synthesis, assets or utils layers into a hard failure** (`src/analyzer/orphan-rewriter.ts`, `src/synthesis/macro-expander.ts`, `src/synthesis/context-providers/index.ts`, `src/assets/asset-storage.ts`, `src/utils/expected-bucket-owner.ts`, `src/utils/error-handler.ts`, go-to-k/cdkd#3361). `String()` throws for a null-prototype object, and these handlers built their message with it. The handler itself then threw: a failed live `Fn::GetAtt` read in `cdkd orphan` rejected the rewrite instead of being reported as unresolvable (or, under `--force`, falling back to the recorded attribute); a failed `DeleteStack` of the macro-expansion transient stack failed the deploy from its cleanup; one failed context lookup lost every other value of that synth round; a failed asset-storage auto-create failed the deploy instead of falling back to the CDK bootstrap destinations; a failed `ExpectedBucketOwner` resolution rejected the state-bucket call instead of omitting the header; and `formatError` / `normalizeAwsError`, whose last arm exists for a non-`Error` value, threw on it. Each now goes through `describeAwsFailure(x).detail` or `safeStringify(x)`, byte-identical for every value `String()` converts and a placeholder otherwise. Tests: `tests/unit/{analyzer/orphan-rewriter,assets/asset-storage}-string-outthrow-3361.test.ts`, `tests/unit/{synthesis,utils}/string-outthrow-3361.test.ts`.

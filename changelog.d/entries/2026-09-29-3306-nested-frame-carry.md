- **A 1-3 character secret in a nested-stack parameter whose token sits in a nested `Fn::Join` / `Fn::Sub` part, in a used `Fn::Sub` variable, or inside an `Fn::If` around the frame is no longer persisted in plaintext in the child, the parent's row or a grandchild's log lines (issue [#3306](https://github.com/go-to-k/cdkd/issues/3306))** -- `src/deployment/intrinsic-function-resolver.ts`, `src/deployment/secret-redaction.ts`; cases in `tests/unit/deployment/nested-stack-refused-frame-carry.test.ts`. The sub-floor carry certifies a frame on the resolver's record of the parameter's own object, and that record spelled only the outer object's own tokens. It now takes a nested `Fn::Join` / `Fn::Sub` / `Fn::If` part's record, and a used `Fn::Sub` variable's raw text (or, for an intrinsic variable, its record), so the token reaches the record raw beside the replacement that resolved it. An `Fn::If` records its selected branch's resolution; a string branch records its own pass, and a branch with no record, or two resolutions in one pass that record differently, poison it. Still refused, as refusals of a wrong reference or of a carried plaintext (listed on `recordNestedStackParameterExpressions`): a public or multiple replacement, a token in a part with no record of its own (an `Fn::Select` element), a spelling holding another recorded secret anywhere, the token included, where only a plaintext equal to the frame's own value is let through, and only inside its token (a `{{resolve:ssm:/app/${Name}}}` whose `Name` is a secret is no longer carried; the parent's own row still takes such a token through the position pass, go-to-k/cdkd#4166), and two outside-the-token frames of one value through different tokens. Resolved values are unchanged.

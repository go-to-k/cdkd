- **`cdkd diff` no longer prints a recorded secret held in a stored Outputs key (issue [#4015](https://github.com/go-to-k/cdkd/issues/4015))** -- `src/cli/commands/diff-recursive.ts` (`renderOutputChangeLines`, `diffTreeToJson`) and `src/analyzer/outputs-diff.ts` (`computeOutputsDiff`, `secretSpanInStoredKey`), with unit tests in `tests/unit/cli/diff-output-key-secret-4015.test.ts`. A binary from before issue #1919 could publish an export alias whose `Export.Name` resolved to a secret as a state KEY, and the diff printed each Outputs row name with only a control-character strip, so that secret reached the terminal and CI logs, contiguous or split by U+2028 / U+2029 (which the logger blanked to a space). Each row name, and the `--json` `name`, now prints only the verdict of the secret test `cdkd scrub` applies to such keys: the name as is, masked (`app-***`), or `<name withheld: contains a secret>`; `--json` adds `nameRedacted: true` when the name is not the stored key. The diff fetches no secret, so it tests against what it can know: the stretch of a stored key that a secret-bearing `Export.Name`'s `{{resolve:...}}` tokens cover (condition-false exporters included), and the stored values of a pre-redaction record's secret outputs and of keys the template no longer declares. Beyond that search, a REMOVED export alias is withheld in a stack whose template references a secret: a key the template no longer declares that holds a character an Output logical id cannot and, where the record lists `exportNames`, is listed. A removed ordinary Output still prints its name. Two gaps remain, each printing unless the search finds its secret: an alias of only letters and digits, and any alias in a stack whose template no longer references a secret by a `secretsmanager` / `ssm-secure` spelling. A stale alias sharing a secret-bearing name's literal ends is masked too.

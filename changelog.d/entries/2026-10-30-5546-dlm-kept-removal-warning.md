- **`AWS::DLM::LifecyclePolicy` warns when a property removed from the template keeps its current value (issue [#5546](https://github.com/go-to-k/cdkd/issues/5546))** -- `src/provisioning/providers/dlm-lifecycle-policy-provider.ts`. Removing `Description`, `ExecutionRoleArn`, `State`, `PolicyDetails`, `CreateInterval`, `RetainInterval`, `CopyTags`, `ExtendDeletion`, `CrossRegionCopyTargets` or `Exclusions` sends nothing to `UpdateLifecyclePolicy`, so the policy keeps the old value, as CloudFormation does (measured with a CloudFormation update that removed each one). Before this change the deploy said nothing; now it prints one warning naming each kept property.

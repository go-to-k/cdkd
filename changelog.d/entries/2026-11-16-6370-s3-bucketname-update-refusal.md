- **`S3BucketProvider.update()` now refuses a changed `BucketName` instead of reporting a replacement it never made (issue [#6370](https://github.com/go-to-k/cdkd/issues/6370))** -- `src/provisioning/providers/s3-bucket/update-delete.ts`. The arm returned `wasReplaced: true` with the old bucket's id and created nothing. The deploy then printed `was replaced: <old> -> <old>` and recorded the new name over the old bucket. The diff classifies a `BucketName` change as a replacement before `update()` runs, so this arm only guards against a future routing change. It now throws the error that `--replace` acts on, and names the replace flags.

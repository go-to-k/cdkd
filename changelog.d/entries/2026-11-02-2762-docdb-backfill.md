- **`AWS::DocDB::DBCluster` and `AWS::DocDB::DBInstance` deploy with more properties (go-to-k/cdkd#2762)** -- `src/provisioning/providers/docdb-provider.ts`. A cluster that declares `AvailabilityZones`, `CopyTagsToSnapshot`, `EnableCloudwatchLogsExports`, `ManageMasterUserPassword`, `MasterUserSecretKmsKeyId`, `NetworkType`, `RotateMasterUserPassword`, `ServerlessV2ScalingConfiguration` or `StorageType`, and an instance that declares `CACertificateIdentifier`, `CertificateRotationRestart` or `EnablePerformanceInsights`, is no longer refused pre-flight. Removing one keeps the live value with a warning, as a real CloudFormation A/B measured; `NetworkType` and `ManageMasterUserPassword` are unmeasured and the warning claims no parity. `RotateMasterUserPassword: true` rotates once, when the template turns it on, and a cluster with a managed password never sends `MasterUserPassword`. An update also waits for a changed log export, `NetworkType`, `StorageType`, serverless scaling, CA certificate or Performance Insights setting to read back (`--no-wait` skips it). `GlobalClusterIdentifier` stays refused: ModifyDBCluster cannot apply a change to it.

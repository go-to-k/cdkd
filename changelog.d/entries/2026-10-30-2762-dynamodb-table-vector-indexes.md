- **`AWS::DynamoDB::Table` keeps the SDK route for `VectorIndexes` (issue [#2762](https://github.com/go-to-k/cdkd/issues/2762)).** A table declaring vector indexes used to go through Cloud Control. They are now sent on `CreateTable`, added and removed on update through `UpdateTable`'s `VectorIndexUpdates` (one index per call, waiting for each to settle), and read back for `cdkd drift`. A same-name vector index whose definition changed is refused before any call, since DynamoDB cannot modify one in place: rename it so it is dropped and re-created. Source: `src/provisioning/providers/dynamodb-table-provider.ts`, `src/provisioning/dynamodb-vector-indexes.ts`.

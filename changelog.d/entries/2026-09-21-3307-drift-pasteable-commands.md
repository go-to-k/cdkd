- **`cdkd drift`'s four pasteable write commands no longer interpolate a state-key stack name raw (issue [#3307](https://github.com/go-to-k/cdkd/issues/3307))** -- `src/cli/commands/drift.ts`, tests. The legacy region-less refusal (`cdkd deploy`), both `--revert` retry hints (`cdkd drift --revert`) and the unbaselined-values note (`cdkd state refresh-observed`) built a command from `listStacks`'s stack name — an S3 KEY — with no sanitizing, quoting or exactness gate, inside a prose `'...'`. A name such as `a; echo INJECTED; #` turned the line into a second command when pasted, a newline or bidi override forged it, and a name sanitizing ALTERS addresses a different record. A new `stackCommandFor` gates all four: sanitize (`asciiOnly`) and compare against the RAW, cap at `STACK_REF_MAX_CODE_POINTS` (a legitimate `Parent~Child~...` still renders), shell-quote, and refuse a name the COMMAND would read as something else — a leading `-` is an option to all four, `*` / `/` patterns to `cdkd deploy`. Withheld, the message names the command in prose and the legacy refusal sends the operator to `cdkd state list --json`. Emitted, it prints LAST on a labelled line (`Migrate with:` / `Revert with:` / `Re-run with:` / `Refresh with:`) rather than in the sentence's quotes — [#3363](https://github.com/go-to-k/cdkd/pull/3363)'s layout, after a quoted value in prose was measured running as shell. The three sites holding a region pass `--stack-region`, so the command addresses the record the run loaded. That refusal also stops naming the stack in its sentence, which interpolated the key RAW, so a pasted phrase ran `$(printf X)`; the name now rides a shell-quoted `Stack:` line, withheld with the command. The other three sites' prose identity is unchanged — [#3232](https://github.com/go-to-k/cdkd/issues/3232)'s display class. The class beyond `drift.ts` is [#3436](https://github.com/go-to-k/cdkd/issues/3436), which excludes these four.

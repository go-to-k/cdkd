- **Removing `AlpnPolicy`, `MutualAuthentication`, `Certificates`, `SslPolicy`, `Port` or `Protocol` from an `AWS::ElasticLoadBalancingV2::Listener` now warns that the live value stays** -- `src/provisioning/providers/elbv2-provider.ts`. `ModifyListener` keeps any field it is not sent, so a removed one stayed live while the deploy reported success and the next `cdkd diff` showed no change. cdkd still sends no reset, since CloudFormation's behavior on these removals is unmeasured, and now names each removed property in one warning after the update succeeds. `SslPolicy` and `Certificates` are not named on an HTTPS to HTTP or TLS to TCP change, where AWS drops them itself. `drift --revert` prints no such warning. Issue [#1160](https://github.com/go-to-k/cdkd/issues/1160).

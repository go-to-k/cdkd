- **Every command that synthesizes the app takes the AWS CDK CLI's `--lookups` / `--no-lookups` and honors `cdk.json` `"lookups"` (issue [#6883](https://github.com/go-to-k/cdkd/issues/6883))** -- `src/cli/options.ts`, `src/synthesis/synthesizer.ts`, `src/cli/config-loader.ts`, the command option types. Both spellings were rejected as unknown options and `"lookups": false` was ignored, so cdkd always looked missing context up and wrote `cdk.context.json`. With lookups disabled, an app that reports missing context now fails synthesis with the CDK CLI's `Context lookups have been disabled.` message naming the missing keys, before any context-provider call and without writing `cdk.context.json`. Precedence follows the CDK CLI: the flag, then `cdk.json`, then `~/.cdk.json`, then on. A pre-synthesized assembly (`-a <dir>`) is read as before.

- **Every command that synthesizes the app takes the AWS CDK CLI's `--lookups` / `--no-lookups` (issue [#6883](https://github.com/go-to-k/cdkd/issues/6883))** -- `src/cli/options.ts`, `src/synthesis/synthesizer.ts`, the command option types. Both spellings were rejected as unknown options, so cdkd always looked missing context up and wrote `cdk.context.json`. With `--no-lookups`, an app that reports missing context now fails synthesis with the CDK CLI's `Context lookups have been disabled.` message naming the missing keys, before any context-provider call and without writing `cdk.context.json`; a pre-synthesized assembly (`-a <dir>`) that still reports missing context is refused the same way. Lookups stay on unless the flag says otherwise: as with `cdk`, a `"lookups"` key in `cdk.json` has no effect.

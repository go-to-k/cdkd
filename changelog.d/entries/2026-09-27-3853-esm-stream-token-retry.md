- **A DynamoDB-stream `AWS::Lambda::EventSourceMapping` created alongside its function's new role is retried instead of failing the deploy (issue [#3853](https://github.com/go-to-k/cdkd/issues/3853))** -- `src/deployment/retryable-errors.ts`, with unit tests in `tests/unit/deployment/retryable-errors.test.ts`. Lambda reads a DynamoDB stream with the function's role when the mapping is created, and a role that IAM has not finished propagating fails that read with "Received Exception while reading from provided stream. The security token included in the request is invalid." cdkd did not classify that wording as IAM propagation, so the deploy failed and rolled back on a transient race. It is now retried with the other IAM-propagation errors. cdkd's own expired credentials, which carry the bare token sentence without Lambda's prefix, still fail immediately.

- **A secret-derived name no longer splits a longer secret in a Glue, S3 bucket or IAM failure or retry line (issue [#4193](https://github.com/go-to-k/cdkd/issues/4193))** -- `src/provisioning/masked-retry-logger.ts`. `withDerivedNameMasks` replaced a physical name derived from a secret with `***` before the deploy's masker ran, so when AWS echoed another recorded secret containing that name (`prod-db` recorded, and `prod-db owner hunter2x` as a description), the longer secret no longer occurred whole and its remainder printed (`Description '*** owner hunter2x' is invalid.`). The deploy's masker now runs first and the derived names after it, each name itself passed through that masker first (at 4 characters or longer) so it still matches where the masker rewrote part of it (`stack-***-example-com`); the line now reads `Description '***' is invalid.`. Where another recorded secret overlaps the name's edge, or contains the name, in the text, the whole line is withheld as `***` rather than printing the rest of the name. This reaches the Glue, S3 bucket and IAM providers' failure and retry lines and the rollback's replay lines. Tests: `tests/unit/provisioning/masked-retry-logger-secret-derived.test.ts`.

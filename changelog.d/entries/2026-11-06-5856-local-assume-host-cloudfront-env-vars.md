- **`cdkd local start-alb --assume-host <[listenerPort=]host>` and `cdkd local start-cloudfront --env-vars <file>` (issue [#5856](https://github.com/go-to-k/cdkd/issues/5856))** -- `package.json` (`cdk-local` `^0.159.0` -> `^0.160.0`), `docs/local-start-alb.md`, `docs/local-start-cloudfront.md`, `docs/local-emulation.md`, `docs/local-emulation-value-resolution.md`. `--assume-host` routes every request as if it carried the given `Host`, so a browser on `localhost` reaches a listener rule that matches only a production host name, and the target receives that host. `--env-vars` overrides the environment of a distribution's Function URL and Web Function origins with the same file format as the other `cdkd local` commands. Both let an app run the emulators against its deployed stage definition unchanged and keep local-only values in the command's arguments.

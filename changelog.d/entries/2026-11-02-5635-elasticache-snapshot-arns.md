- **`AWS::ElastiCache::CacheCluster` sends `SnapshotArns` on the SDK route (go-to-k/cdkd#5635)** -- `src/provisioning/providers/elasticache-provider.ts`. A cluster seeded from an RDB file in S3 is now created by CreateCacheCluster with its `SnapshotArns`, instead of routing the whole cluster through Cloud Control and recording it there. The property is create-only, so a change replaces the cluster, as CloudFormation does. A cluster already recorded as `provisionedBy: cc-api` stays on Cloud Control.

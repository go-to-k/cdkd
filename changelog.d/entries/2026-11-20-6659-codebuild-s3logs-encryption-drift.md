- **`cdkd drift` no longer reports a CodeBuild project's `LogsConfig.S3Logs.EncryptionDisabled` as drifted from absent to `false` after `cdkd drift --revert` (issue [#6659](https://github.com/go-to-k/cdkd/issues/6659))** -- `src/provisioning/providers/codebuild/drift.ts`, `src/provisioning/providers/codebuild-provider.ts`, unit tests. AWS reports no `encryptionDisabled` for a project created without a `logsConfig` and `false` once a revert has re-sent the recorded `LogsConfig`, so a baseline captured before the revert drifted on every run after it. Drift now compares an absent `EncryptionDisabled` as `false`, its default, which also heals a baseline written by an earlier cdkd. A `true` on either side is still reported.

- **`AWS::Events::EventBus`: a template-declared `Policy` is now applied to the bus (issue [#5044](https://github.com/go-to-k/cdkd/issues/5044))** -- `src/provisioning/providers/eventbridge-bus-provider.ts`. Before, the provider declared `Policy` handled but never sent it, so the deploy succeeded and the bus had no resource policy: a cross-account `PutEvents` the policy granted was refused. The bus is now created and then given the whole document through `PutPermission` (an object or a JSON string). An update with a changed `Policy` replaces the whole bus policy, statements a separate `AWS::Events::EventBusPolicy` added included, as CloudFormation does; an update that leaves `Policy` unchanged sends nothing for it, and removing `Policy` from the template leaves the live policy in place, as CloudFormation leaves it, with a warning saying so. A create or update refused by AWS now names the error class and points to `--verbose` instead of relaying AWS's text, which can carry the caller's assumed-role ARN into the persisted deployment journal (issue [#2319](https://github.com/go-to-k/cdkd/issues/2319)). Tests: `tests/unit/provisioning/eventbridge-bus-policy-5044.test.ts`, integ `tests/integration/eventbus-policy`.

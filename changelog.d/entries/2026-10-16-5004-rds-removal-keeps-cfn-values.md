- **Removing `DeletionProtection`, `EnableIAMDatabaseAuthentication` (RDS DBCluster / DBInstance) or `MonitoringInterval` (RDS DBInstance) from the template no longer resets it, matching CloudFormation (issue [#5004](https://github.com/go-to-k/cdkd/issues/5004))** -- A real CloudFormation A/B showed CloudFormation KEEPS the live value of these properties when they are removed, while cdkd reset them (`DeletionProtection` to false, `EnableIAMDatabaseAuthentication` to false, `MonitoringInterval` to 0). cdkd now sends no value for them, so the live setting is left as it is; a protected cluster or instance stays protected after the property is removed, and `cdkd destroy --remove-protection` still lifts it. DBCluster `BackupRetentionPeriod` (CloudFormation resets it to 1) is unchanged, and DBCluster `MonitoringInterval` is unchanged because it could not be measured. Changed: `src/provisioning/providers/rds-provider.ts`, `tests/unit/provisioning/rds-provider-update-removal.test.ts`, `tests/integration/rds-aurora/`, `tests/integration/rds-dbinstance-backfill/`.

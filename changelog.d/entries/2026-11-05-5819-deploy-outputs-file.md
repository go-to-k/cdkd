- **`cdkd deploy --outputs-file <path>` (`-O`) writes every deployed stack's outputs to a JSON file, as `cdk deploy --outputs-file` does (issue [#5819](https://github.com/go-to-k/cdkd/issues/5819))** -- `src/cli/commands/outputs-file.ts`, `src/cli/commands/deploy.ts`, `src/cli/config-loader.ts`, `docs/stack-outputs.md`, `docs/cli-deploy.md`. The file maps each stack's CloudFormation name to its outputs (`{}` for a stack without any), replaces an existing file and creates missing parent directories. `outputsFile` in `cdk.json` sets the path when the flag is absent. A failed deploy still writes the outputs of the stacks that did deploy; `--dry-run` writes nothing. Values are the ones the console prints, so a masked secret is written as `***`.

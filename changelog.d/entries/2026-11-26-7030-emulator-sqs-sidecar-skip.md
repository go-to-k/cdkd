- **`cdkd local` under `--aws-emulator` no longer starts the SQS queue URL sidecar for an AWS Emulator that already returns local queue URLs (issue [#7030](https://github.com/go-to-k/cdkd/issues/7030))** -- `package.json` (`cdk-local` `^0.169.3` -> `^0.170.0`, with go-to-k/cdk-local#1023), `docs/aws-emulator.md`. AWS Emulator 1.0.580 and later (aws/aws-emulator#25) answer `CreateQueue` / `GetQueueUrl` / `ListQueues` with a URL on the emulator itself, so the sidecar that rewrote real-shaped queue URLs had nothing left to do. cdk-local's workload wiring now sends one read-only `ListQueues` at startup and skips the sidecar when the queue URL it returns is local; a real-shaped URL (an older emulator), no queue in the region yet, or no answer keeps the sidecar. Mixed mode is unchanged. No cdkd source change.

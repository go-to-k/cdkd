- **`cdkd deploy` warns again before dropping the stack-name prefix from an explicitly named IAM / ELBv2 resource** -- `src/cli/commands/prefix-migration-check.ts`, with a unit test. The pre-deploy check that lists resources the v0.94 default would REPLACE (a `--prefix-user-supplied-names` stack deployed without the flag) runs inside the deploy's own prefix scope, so it computed the legacy name without the prefix and never found anything: the warning and its confirmation prompt were silently skipped and the resources were replaced. The legacy name is now always computed with the prefix. Found by the `rollback-explicit-name-rewrite` integ fixture (issue [#4024](https://github.com/go-to-k/cdkd/issues/4024)).

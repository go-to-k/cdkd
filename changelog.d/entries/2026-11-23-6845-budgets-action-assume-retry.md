- **A Budgets action created in the same deploy as its execution role no longer fails on IAM propagation (issue [#6845](https://github.com/go-to-k/cdkd/issues/6845))** -- `src/deployment/retryable-errors/patterns.ts`, `tests/unit/deployment/retryable-errors.test.ts`, `tests/integration/budgets-action`. Budgets checks at create time that it can assume an `AWS::Budgets::BudgetsAction`'s `ExecutionRoleArn`, and refuses a role IAM has not propagated yet with "Budgets permission required to assume [ExecutionRole: ...]". cdkd treated that as permanent and rolled back, deleting the new role, so every re-run met the same race. cdkd now retries it on the IAM-propagation schedule, as it already does for the same race in other services.

- **`cdkd drift` no longer reports phantom drift when a read-back list entry carries a member AWS left unset (issue [#5727](https://github.com/go-to-k/cdkd/issues/5727))** -- `src/analyzer/drift-calculator.ts` and its unit test. The drift comparator counted an `undefined`-valued key inside a list entry as present, while the stored baseline drops such keys, so an untouched resource could show drift that `cdkd drift --accept` could not clear (#5723 was one case). The comparator now treats an `undefined`-valued key as missing at every depth, as it already did for object properties, so no provider can reintroduce that phantom drift. A member that AWS reports with a value is still compared.

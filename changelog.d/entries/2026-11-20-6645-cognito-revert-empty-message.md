- **`cdkd drift --revert` works on a Cognito user pool that never set a verification or authentication message (issue [#6645](https://github.com/go-to-k/cdkd/issues/6645))**. The drift read reports an unset `EmailVerificationMessage`, `EmailVerificationSubject`, `SmsAuthenticationMessage` or `SmsVerificationMessage` as `''`, and the revert sent that `''` back to `UpdateUserPool`. AWS refuses `''` for all four, so reverting any drift on such a pool failed with `InvalidParameterException`, which hit default CDK user pools, since they set no `SmsAuthenticationMessage`. The `''` placeholder is now left out of the call. Omitting a member clears it on AWS (measured, and the same as CloudFormation when a template drops it), so reverting a message added out of band clears it, and a changed message is still restored. Files: `src/provisioning/providers/cognito/update.ts`, `tests/unit/provisioning/cognito-provider-roundtrip.test.ts`.

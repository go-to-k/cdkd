- **`AWS::KinesisFirehose::DeliveryStream` sends `MSKSourceConfiguration` on the SDK route (issue [#5636](https://github.com/go-to-k/cdkd/issues/5636))** -- `src/provisioning/providers/firehose-provider.ts` forwards the block on `CreateDeliveryStream` and reads it back for drift, so a newly deployed stream with an Amazon MSK source no longer falls back to Cloud Control (an existing stream keeps its recorded Cloud Control route). The block is create-only, so a change still replaces the stream. `ReadFromTimestamp` is read as CloudFormation reads it, a string of epoch milliseconds, and any other spelling (an ISO 8601 date included, which CloudFormation also refuses) is refused before the stream is created, naming the property. `DatabaseSourceConfiguration` and `SnowflakeDestinationConfiguration` still route through Cloud Control.

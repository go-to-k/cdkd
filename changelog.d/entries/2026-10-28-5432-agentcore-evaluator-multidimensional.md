- **An AgentCore evaluator's multi-dimensional rating scale now reaches AWS (issue [#5432](https://github.com/go-to-k/cdkd/issues/5432))** -- `package.json` / `pnpm-lock.yaml` (`@aws-sdk/client-bedrock-agentcore-control` 3.1152.0 -> 3.1157.0), a new unit file, and the AgentCore evaluator wire case in `tests/unit/provisioning/sdk-wire-cases-11.ts`. Before, `EvaluatorConfig.LlmAsAJudge.RatingScale.MultiDimensional` on `AWS::BedrockAgentCore::Evaluator` was dropped by the SDK's own serializer, which predated the member: `CreateEvaluator` and `UpdateEvaluator` went out without the rating scale's dimensions, the deploy reported success, and `cdkd drift` could not see the difference because the same client dropped the member from `GetEvaluator` too. The client now models `multiDimensional` (added in 3.1156.0), so create, update and the drift read carry it; no provider code changed, since the provider's PascalCase-to-camelCase conversion already produced the right key. An evaluator deployed with a multi-dimensional scale before this fix was created without it; `cdkd drift` now shows that, and `cdkd drift --revert` (or a redeploy after any `EvaluatorConfig` change) sends it.

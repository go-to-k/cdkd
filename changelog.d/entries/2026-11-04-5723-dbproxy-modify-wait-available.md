- **`AWS::RDS::DBProxy` updates now wait for the proxy to return to `available` after `ModifyDBProxy`** -- `src/provisioning/providers/rds-dbproxy-provider.ts` (`update`). The modify returns while the proxy is `modifying`, so a dependent's update in the same deploy, or the next modify, could be refused with `InvalidDBProxyStateFault`. `update()` now polls `DescribeDBProxies` with the same 30-minute bound as `create()`, failing on a terminal state.

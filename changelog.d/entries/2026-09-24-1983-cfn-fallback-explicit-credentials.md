- **The CloudFormation cross-stack fallback now uses explicitly supplied credentials (issue [#1983](https://github.com/go-to-k/cdkd/issues/1983))** -- `src/deployment/intrinsic-function-resolver.ts` (`getCfnClient`), new cases in `tests/unit/deployment/intrinsic-cfn-fallback.test.ts`. The `Fn::ImportValue` `ListExports` and `Fn::GetStackOutput` `DescribeStacks` fallback client was built from the SDK's default credential chain alone, so a library caller that constructed `AwsClients` with an explicit `credentials` object had those reads made under a different identity. The client now carries the active `AwsClients`' credential configuration (profile and explicit credentials), as the resolver's other lookups already do. CLI runs are unaffected: no command passes explicit credentials, and `--profile` / `--role-arn` already reached this client through the environment. The other SDK clients built outside `AwsClients` (providers, context providers, the cross-account STS hop) are tracked in [#3588](https://github.com/go-to-k/cdkd/issues/3588).

- **Removing an `InputTemplate` from an EventBridge Pipe's `TargetParameters` or `EnrichmentParameters` now clears it on AWS (issue [#6233](https://github.com/go-to-k/cdkd/issues/6233))** -- `src/provisioning/providers/pipes/update.ts`, `pipes/shared.ts`, `pipes-provider.ts`, unit tests and a new `pipes-input-template-removal` integ fixture. Before, `UpdatePipe` kept the member cdkd no longer sent, so the old input transformer went on rewriting every event the pipe delivered. Removing the whole block printed a warning; removing only `InputTemplate` while other target parameters stayed printed nothing. cdkd now sends an empty `InputTemplate`, which clears it, as CloudFormation does on the same removal. Any other member removed from those two blocks is still left in place, and one warning names each of them.

- **`cdkd drift` now compares a CodeCommit repository's `Triggers` (issue [#6854](https://github.com/go-to-k/cdkd/issues/6854))** -- `src/provisioning/providers/codecommit-repository/read-state.ts`, `src/provisioning/providers/codecommit-repository/shared.ts`, `src/provisioning/providers/codecommit-repository-provider.ts`, `tests/integration/codecommit`. The repository read now includes `GetRepositoryTriggers` (run beside the tag read), so a trigger added, removed or changed outside cdkd is reported. A trigger declared without `Branches` compares equal to the `[]` (every branch) CodeCommit holds. A drift baseline recorded before this release has no `Triggers` and compares none until the repository is next deployed or its baseline is refreshed (`cdkd state refresh-observed --yes`).

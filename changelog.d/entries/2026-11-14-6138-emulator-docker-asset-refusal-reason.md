- **`--aws-emulator`: the Docker image asset refusal now gives the current reason** -- `src/assets/docker-asset-emulator-refusal.ts`, `docs/aws-emulator.md`. From AWS Emulator 1.0.338 the emulator's ECR returns a local repository URI, so "its repository URI names the real amazonaws.com registry" no longer explained the refusal; the blocker is that the emulator's registry refuses image pushes (aws/aws-emulator#250). The message and the docs now say so and keep the older reason for earlier emulator versions. Lifting the refusal is tracked in go-to-k/cdk-local#936.

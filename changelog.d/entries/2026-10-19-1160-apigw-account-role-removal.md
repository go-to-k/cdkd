- **Removing `CloudWatchRoleArn` from an `AWS::ApiGateway::Account` now clears the account's CloudWatch role, matching CloudFormation (issue [#1160](https://github.com/go-to-k/cdkd/issues/1160))** -- A real CloudFormation A/B showed CloudFormation clears the region's API Gateway CloudWatch role ARN when the template stops declaring it. `UpdateAccount` is a patch call, and cdkd sent it with no operations for the removed property, so the old role ARN stayed set. cdkd now sends `replace /cloudwatchRoleArn ''` for a removed `CloudWatchRoleArn`, the same clear its delete already sends. Changed: `src/provisioning/providers/apigateway-provider.ts`, `tests/unit/provisioning/apigateway-provider.test.ts`, `tests/integration/apigateway/`.

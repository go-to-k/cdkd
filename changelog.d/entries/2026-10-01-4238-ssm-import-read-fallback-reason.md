- **`cdkd import` of an SSM parameter by an id the AWS CLI itself would act on names that reason when it withholds the read command (issue [#4238](https://github.com/go-to-k/cdkd/issues/4238))** -- `src/provisioning/providers/ssm-parameter-provider.ts`. For an import id holding `:` that starts with `file://` or `-` (for example `file://x` or `-p:1`), the refusal withholds the `aws ssm get-parameter --name ...` command and points to the console. Its explanation used to name only the shell reason. It now uses the shared wording: "or it holds a character or prefix a pasted shell line, or the AWS CLI itself, would act on". Tests: `tests/unit/provisioning/uncached-arn-attributes-issue-1824.test.ts`.

- **The `--recreate-via-cc-api` / `--recreate-via-sdk-provider` confirmation no longer prints a non-plain downstream-consumer value raw (issue [#4165](https://github.com/go-to-k/cdkd/issues/4165))** -- `src/cli/commands/recreate-downstream-consumers.ts` (`renderDownstreamConsumers`), with paste cases in `tests/unit/cli/commands/recreate-downstream-consumers-paste.test.ts`. Each consumer row printed the consumer stack name, its region and the export or output name it reads as they were recorded. The name and region come from the consumer's state key and the export name from its `state.json`, so whoever can write the state bucket chose them. A value could carry a span that ran when the row was pasted into a shell, or a newline that forged an extra consumer row inside the data-loss prompt. A plain value prints exactly as before, a CDK-generated export name carrying `:` included. Any other value is described (`a stack name that is not a plain identifier`, `a region that is not a plain identifier`, `an export whose name is not a plain identifier`, `an output whose name is not a plain identifier`). That includes a redacted `{{resolve:...}}` or `***` name on a row whose producer cdkd cannot name.

- **`AWS::ApiGateway::Deployment` `DeploymentCanarySettings` is wired into the SDK provider (issue [#2762](https://github.com/go-to-k/cdkd/issues/2762))** -- `src/provisioning/providers/apigateway-provider.ts`, `src/provisioning/property-coverage.generated.ts`, `tests/fixtures/cfn-schemas/_todo-backfill.json`, the Deployment unit tests, and the `apigw-stage-props` integ. The property was a silent drop, so a Deployment declaring it was routed through Cloud Control. It now goes on `CreateDeployment` as `canarySettings` (`PercentTraffic`, `StageVariableOverrides`, `UseStageCache`) and the Deployment takes the SDK route. A block that is not an object is refused before any AWS call. The CloudFormation schema marks the block create-only, so a change replaces the deployment, as CloudFormation does. `GetDeployment` does not return it, so `cdkd drift` does not compare it. A Deployment that also declares `StageName` is still routed through Cloud Control.

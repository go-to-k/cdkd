- **A failed context lookup blocks `cdkd local start-service`, `start-alb`, `start-cloudfront`, `start-agentcore`, `start-web-function` and `start-microvm` only when a stack the command serves asked for it (or no stack can be matched to it) (issue [#5812](https://github.com/go-to-k/cdkd/issues/5812))** -- `src/cli/commands/local-host-synthesizer.ts`, `docs/architecture-deploy-pipeline.md`. Before this change, these six commands failed with `Context lookup failed` when a lookup in any stack of the app failed. cdk-local now reports the stacks it serves after it resolves the target, on every reload too, and cdkd checks those stacks as its other commands do.

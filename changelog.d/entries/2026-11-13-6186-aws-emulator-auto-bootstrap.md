- **`cdkd deploy --aws-emulator` bootstraps AWS Emulator itself (issue [#6186](https://github.com/go-to-k/cdkd/issues/6186))** -- `src/cli/commands/emulator-auto-bootstrap.ts`, `src/cli/commands/bootstrap-state-bucket.ts` (the state-bucket half of `cdkd bootstrap`, now shared), `src/cli/commands/deploy/prep.ts` + `helpers.ts`, `src/cli/commands/import/command.ts`. AWS Emulator keeps its state in memory, so every emulator start needed `cdkd bootstrap --aws-emulator` before a deploy. Under `--aws-emulator`, `cdkd deploy` and `cdkd import` now create the state bucket when the emulator has none (the same create + configure calls as `cdkd bootstrap`) with one info line (never under `--dry-run`), and the deploy's per-region asset-storage auto-create no longer prompts. Real AWS is unchanged: a missing state bucket still stops the command, and the `[Y/n]` asset-storage prompt stays.

- **`AWS::ECS::Service`'s `VpcLatticeConfigurations[].AdvancedConfiguration` now reaches AWS instead of being silently dropped (PR [#4324](https://github.com/go-to-k/cdkd/pull/4324))** -- The ECS SDK provider forwards `VpcLatticeConfigurations` through a generic key converter, and `@aws-sdk/client-ecs` 3.1140.0's `VpcLatticeConfiguration` had no `advancedConfiguration` member, so the serializer discarded the block (`AlternateTargetGroupArn`, `ProductionListenerRule`, `TestListenerRule`) on create and update with no error. Changed: `package.json` / `pnpm-lock.yaml` (`@aws-sdk/client-ecs` ^3.1144.0, the first release that models the member).

- **`AWS::ElasticLoadBalancingV2::Listener`: the warning for a removed `AlpnPolicy`, `MutualAuthentication`, `Certificates`, `SslPolicy`, `Port` or `Protocol` now says CloudFormation keeps the value too (issue [#1160](https://github.com/go-to-k/cdkd/issues/1160))** -- `src/provisioning/providers/elbv2-provider.ts`. A CloudFormation A/B on the issue (us-east-1, each property removed alone and beside a `DefaultActions` change) showed CloudFormation keeps all six live values and no update fails. cdkd already kept them, because `ModifyListener` keeps a field it is not sent, so the behaviour does not change. The deploy warning used to make no claim about CloudFormation; it now reads `... were removed from the template and keep their current AWS value, as CloudFormation leaves them; ...`. The rollback wording is unchanged. Tests: `tests/unit/provisioning/elbv2-listener-removal-1160.test.ts`; the `alb` integ fixture gains a phase that drops the listener's `Port` and `Protocol`.

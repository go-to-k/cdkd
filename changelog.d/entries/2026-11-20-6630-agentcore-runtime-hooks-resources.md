- **A Bedrock AgentCore runtime's `HooksConfiguration` (build warmup hook) and `ResourceConfigurations` (minimum memory) stay on the SDK route (PR [#6630](https://github.com/go-to-k/cdkd/pull/6630))**. AWS added both in the 2026-11-19 schema refresh; the `AWS::BedrockAgentCore::Runtime` SDK provider did not send them, so a runtime declaring either would have moved to Cloud Control, and stayed there. The provider now sends both on `CreateAgentRuntime` and on the full-replace `UpdateAgentRuntime`, and reads them back from `GetAgentRuntime` for drift. Removing one from the template clears it, which is what both an omitting `UpdateAgentRuntime` and CloudFormation do on the same edit (measured). The `Port` AWS fills into a warmup hook is not reported as drift. `ResourceConfigurations` needs `PlatformVersion: V2`; AWS refuses it otherwise, and cdkd passes that refusal through. Adds unit coverage.

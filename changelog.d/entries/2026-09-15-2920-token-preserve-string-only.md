- **`cdkd drift --revert` no longer copies a NON-STRING live value into a whole-`{{resolve:...}}`-token position (issue [#2920](https://github.com/go-to-k/cdkd/issues/2920))** -- `src/cli/commands/drift.ts` (`preserveLiveValuesAtUnresolvedTokens`), `docs/cli-drift.md`, unit tests. The token preserve arm copied whatever AWS held at a whole-token leaf without a type test, so a live object, array, number or `null` at a position the baseline types as a string was shipped to `provider.update` -- the #2855 wrong-shape class through the preservation arm, reachable on every pairing route and widened by PR #2912's forced 1-vs-1 singleton. Only a string is copied now; otherwise the token is KEPT, this pass's documented residual (what `cdkd deploy` sends). The sibling mask walk keeps its opposite choice, because its refusal drops the whole resource.

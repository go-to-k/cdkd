- **A Cognito user pool whose SMS role is created in the same deploy no longer fails while the role's `sns:Publish` grant propagates (issue [#5809](https://github.com/go-to-k/cdkd/issues/5809))** -- `src/deployment/retryable-errors/patterns.ts` and its unit tests. IAM makes a new SMS role usable in two stages. Until the trust policy is visible, Cognito answers `InvalidSmsRoleTrustRelationshipException`, which cdkd already waited out (#2901). Until the inline `sns:Publish` grant is visible, it answers `InvalidSmsRoleAccessPolicyException` ("Role does not have permission to publish with SNS"). That second answer was not treated as propagation, so the deploy gave up the moment the first stage cleared. cdkd now retries it on the same IAM-propagation schedule. A role that truly lacks `sns:Publish` still fails with the same error, once that schedule has run out.

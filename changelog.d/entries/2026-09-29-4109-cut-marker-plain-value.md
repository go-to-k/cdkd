- **A bootstrap-marker name, or a `lock.json` owner / operation in `cdkd state show` / `cdkd state orphan`, that is not a plain identifier is no longer printed raw (issue [#4109](https://github.com/go-to-k/cdkd/issues/4109))** -- `src/assets/asset-storage.ts` (`isPlainName`, `shownName`), `src/cli/commands/state.ts` (`plainValueOrDescribed`, `formatLockSummary`), `src/deployment/replacement-name-holder.ts`. Two predicates decided "plain" by `displayIdent` returning the value unchanged, and a value that IS `displayIdent`'s cut output (`<cap characters> [cut: N more characters withheld]`) returns unchanged too, so it was printed raw inside cdkd's quotes or beside a labelled row. Whitespace is now refused first. `cdkd state show`'s `Lock:` row described nothing, so an owner such as `x (operation: deploy), expired 3h ago` made a live lock read as expired; its owner and operation are now described unless plain (the lock manager's own messages: issue [#4115](https://github.com/go-to-k/cdkd/issues/4115)). `cdkd bootstrap`'s progress lines print a marker-supplied bucket / repository name through `displayIdent`, so a real name reads as before. The name-collision refusal now reads `asks for a name (AlarmName) that is not a plain identifier` instead of `a AlarmName`. Tests: `tests/unit/assets/asset-storage.test.ts`, `tests/unit/cli/state-orphan.test.ts`, `tests/unit/cli/state-show.test.ts`, `tests/unit/cli/state-record-shape.test.ts`, `tests/unit/deployment/replacement-name-holder-prose-quotes.test.ts`.

- **A launch configuration created right after its instance profile is retried instead of failing the deploy (issue [#6740](https://github.com/go-to-k/cdkd/issues/6740))** -- `src/deployment/retryable-errors/patterns.ts`. Auto Scaling spells the IAM propagation race `Invalid IamInstanceProfile: <name>`, which the existing EC2 (`Invalid IAM Instance Profile`) and EMR (`Invalid InstanceProfile`) patterns did not match, so a CDK `AutoScalingGroup` on a launch configuration could fail its first deploy and roll back.

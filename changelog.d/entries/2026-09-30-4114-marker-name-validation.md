- **A bootstrap marker naming an invalid asset bucket or ECR repository is treated as malformed (issue [#4114](https://github.com/go-to-k/cdkd/issues/4114))** -- `src/assets/asset-storage.ts` (`parseBootstrapMarker`), `src/cli/commands/gc.ts` (comment). `--asset-bucket` / `--container-repo` are validated before any AWS call, but a name read from the marker's body was sent to S3 / ECR as-is, and anyone with `s3:PutObject` on the state bucket chooses that body. The marker's names are now held to the same rules. `cdkd bootstrap` warns and rewrites such a marker with the conventional or flag-supplied names, as it already did for a malformed one. `cdkd deploy`, `cdkd gc` and `cdkd bootstrap --destroy` refuse it with the malformed-marker error, and never send or delete by the invalid name. Tests: `tests/unit/assets/asset-storage.test.ts`.

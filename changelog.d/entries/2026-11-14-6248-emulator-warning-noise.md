- **Less noise under `--aws-emulator`, and a bad option value is now a one-line usage error (issues [#6248](https://github.com/go-to-k/cdkd/issues/6248), [#6249](https://github.com/go-to-k/cdkd/issues/6249), [#6251](https://github.com/go-to-k/cdkd/issues/6251))**. Changed: `src/local/docker-runner.ts`, `src/provisioning/{describe-type,create-only-properties,write-only-properties,read-only-properties}.ts`, `src/provisioning/cloud-control/import.ts`, `src/cli/arg-parser.ts` (new), `src/cli/run-cli.ts`, the option registrations, and unit tests.
  - A local `BucketDeployment` run no longer warns `Env var(s) "AWS_CA_BUNDLE" ... Rename the env var`. The container now gets the emulator CA in `AWS_CA_BUNDLE`. A collision cdkd does not replace still warns.
  - A `TypeNotFoundException` from the emulator's registry now prints one info line per run, not a `Grant cloudformation:DescribeType` warning per type. `cdkd import` still warns that the type's attributes are masked, but without the grant advice. Real AWS is unchanged.
  - An invalid value for `gc --older-than`, `--resource-timeout`, `--resource-warn-after`, `events prune --keep`, `local invoke-agentcore --timeout`, `local start-api --assume-role` or a provisioning-route flag used to print `Fatal error:` and a stack trace. It now prints a one-line usage error and exits 1. A value with a control character is never echoed raw.
  - The deploy / publish-assets concurrency options and `drift --concurrency` now require a positive integer. Before, `bogus` became `NaN`: `deploy --dry-run` accepted it, and `drift --revert` reverted nothing.

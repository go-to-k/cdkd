- **A wide API Gateway REST API deploys and destroys without `TooManyRequestsException` (issue [#5283](https://github.com/go-to-k/cdkd/issues/5283))** -- `src/utils/apigateway-pacing.ts`, `src/utils/aws-clients.ts`, `src/provisioning/providers/apigateway-provider.ts`. cdkd sent up to 52 `CreateResource` and 74 calls per second against API Gateway's per-account limits of 5 and 10, the SDK gave up after 3 attempts, and a `Method` whose cleanup was throttled too stayed behind and failed the replay with `Method already exists for this resource`. The API Gateway clients now space calls before every attempt, retries included: 8 per second overall and 4 per second for `CreateResource`, `DeleteResource`, `CreateApiKey` and `DeleteApiKey`, one pacer per Region, and the SDK attempts go from 3 to 8 for other callers of the same account. Measured on a 122-resource stack: deploy and destroy succeed (they failed before), throttled `CreateResource` calls 348 to 13. Unit cases in `tests/unit/utils/apigateway-pacing.test.ts`, including a real SDK client against a stub handler.

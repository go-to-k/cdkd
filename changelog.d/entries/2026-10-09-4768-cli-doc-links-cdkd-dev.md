- **CLI messages that point to documentation now link to the matching cdkd.dev section instead of a GitHub blob URL (PR [#4768](https://github.com/go-to-k/cdkd/pull/4768))** -- `src/cli/commands/local-start-api.ts`, `src/utils/role-arn.ts`.

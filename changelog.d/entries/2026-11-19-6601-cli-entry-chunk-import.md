- **No bundled chunk imports the `dist/cli.js` entry any more (issue [#6601](https://github.com/go-to-k/cdkd/issues/6601))** -- `vite.config.ts` and `tests/unit/cli/dist-entry-chunks.test.ts`. The bundler had moved `src/utils/cache-home.ts`, which the CLI's compile-cache setup and `src/local/rie-mount.ts` share, into the `cli.js` entry chunk, so the lazily loaded command-tree chunk imported `cli.js` and, through it, so did the provider-classes chunk. Anything loading those chunks outside the `cdkd` command (the `ec2-instance` integration probe) ran the CLI's top-level `main()`, which parsed that process's own arguments and exited with `error: unknown command`. The build now keeps the entry chunks' export signatures strict, so a shared module lands in a chunk of its own. The `cdkd` command and the `dist/index.js` library entry were not affected (the library entry never loads the command-tree chunk), and `cdkd` startup time is unchanged.

- **`cdkd export` names the remedy a refused import baseline and a masked property really have (issues [#3465](https://github.com/go-to-k/cdkd/issues/3465), [#2881](https://github.com/go-to-k/cdkd/issues/2881))** -- `src/cli/commands/export.ts`, `docs/cli-export.md`. The drift-baseline report told every resource whose baseline a `cdkd import` refused to "deploy a change to each one", which does not clear an `unverifiable-parameter` refusal, nor one an older cdkd recorded without a reason when the resource reads a template parameter. The list is now grouped by remedy through the same `refusedBaselineRemedy` text `cdkd state show` and `cdkd drift` print, and a reason-less refusal is classified against the template being exported, as the next deploy reads it. The block on a resource whose recorded properties hold the redaction mask `***` named a `NoEcho` Custom Resource value and a mask copied from another record as its only causes; it now also names the `Fn::Base64` encoding of a secret, which every deploy masks again, so its remedy is to stop encoding the secret into the property. Tests: `tests/unit/cli/export.test.ts`.

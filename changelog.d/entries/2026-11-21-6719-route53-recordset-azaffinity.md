- **A Route 53 record set's `AZAffinity` stays on the SDK route (issue [#6719](https://github.com/go-to-k/cdkd/issues/6719))**. The `AWS::Route53::RecordSet` SDK provider did not send `AZAffinity` (AZ-affinity routing), so a record declaring it moved to Cloud Control, and stayed there. The provider now sends `LocationType` and `LocationId` on `ChangeResourceRecordSets` (create, update and the delete's exact-match address) and reads them back for drift. `@aws-sdk/client-route-53` moves to 3.1174.0, the first release that models the field. Files: `src/provisioning/providers/route53-provider.ts`, `src/provisioning/providers/route53/{record-set,record-set-group-shape,read-state}.ts`, `tests/unit/provisioning/route53-recordset-azaffinity-6719.test.ts`, `tests/integration/route53/`.

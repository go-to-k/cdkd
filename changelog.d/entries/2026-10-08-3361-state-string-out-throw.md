- **A state-bucket call rejecting with a value that cannot be converted to text no longer turns a best-effort state-layer step into a hard failure** (`src/state/deployment-events-store.ts`, `src/state/export-index-store.ts`, `src/state/s3-noncurrent-version-purge.ts`, go-to-k/cdkd#3361). Five handlers that log a failure and carry on, plus the noncurrent-version purge's failure recorder, built their message with `x instanceof Error ? x.message : String(x)`, and `String()` throws for a null-prototype object. The handler itself then threw: `DeploymentEventsStore.finalize`, documented as never throwing, rejected out of the deploy and destroy runners' `finally`; an unreadable deployment-events index skipped the index write; one unreadable state record during an exports-index rebuild failed every lookup instead of skipping that stack; a failed or retry-exhausted exports-index write rejected instead of continuing on `state.json`; and a purge stopped at the first failed listing or batch and rejected. Each now goes through `describeAwsFailure(x).detail`, byte-identical for an `Error` and a placeholder otherwise. Tests: `tests/unit/state/state-string-outthrow-3361.test.ts`.

- **The published Node.js floor is now 22.12.0 — Node 20 (end of life 2026-04-30) is no longer supported (issue [#3037](https://github.com/go-to-k/cdkd/issues/3037))** -- `package.json` (`engines.node` `>=22.12.0`), `vite.config.ts` (`vp pack` target `node22`), `.github/workflows/ci.yml` (the `runtime-compat` matrix smokes the built CLI on exactly 22.12 — the floor row — and on 24), README / `docs/getting-started.md` / `docs/testing.md` / `CONTRIBUTING.md` and the agent-facing pages that state the range. installing on Node 20 now warns (npm `EBADENGINE`, pnpm `Unsupported engine`) and is refused under `engine-strict`, instead of installing silently onto an unsupported runtime; 22.12 is the floor `commander@15` declares, so the next `commander` major cannot move the floor again as a side effect of a dependency bump. The five surfaces are pinned to one another by `tests/unit/scripts/node-floor-sync.test.ts`, which goes red when any one of them moves alone. Under `bump-minor-pre-major` this lands as a MINOR release. The dev / CI pin (`.node-version`, 24.15.0) is unchanged. The same floor lands in cdk-local ([#722](https://github.com/go-to-k/cdk-local/issues/722)) and cdk-real-drift ([#1905](https://github.com/go-to-k/cdk-real-drift/issues/1905)) in the same pass.

- **`--remove-protection` keeps a user pool's custom ACR level names (PR [#4839](https://github.com/go-to-k/cdkd/pull/4839))** -- `src/provisioning/providers/cognito-provider.ts`. The AWS SDK bump adds `AcrConfiguration` to `UpdateUserPool`, and the API reference says a level the write does not name falls back to its default name. The `DeletionProtection` flip now echoes it with the other read-back members, so a destroy that is refused after the flip no longer leaves the pool with its ACR names reset (#4066). Tests: `tests/unit/provisioning/providers/cognito-remove-protection-rmw.test.ts`.

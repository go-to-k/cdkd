- **`--remove-protection` keeps a user pool's custom ACR level names (PR [#4839](https://github.com/go-to-k/cdkd/pull/4839))** -- `src/provisioning/providers/cognito-provider.ts`. The AWS SDK bump adds `AcrConfiguration` to `UpdateUserPool`, and the API reference says a level a write does not name gets its default name, so the `DeletionProtection` flip could reset the custom names of an Essentials or Plus pool. The flip now echoes the custom-named levels with the other read-back members (#4066). Levels carrying their default `urn:cognito:loa:<n>` are not sent, so a pool with no custom name -- every Lite pool -- gets no `AcrConfiguration` in the write. Tests: `tests/unit/provisioning/providers/cognito-remove-protection-rmw.test.ts`.

- **A failure that cannot be converted to text no longer turns a degradation in `cdkd drift` into a failure of the command or of a revert that already landed** (`src/cli/commands/drift.ts`, go-to-k/cdkd#3361). Thirteen handlers that log a failure and carry on built their message with `x instanceof Error ? x.message : String(x)`, and `String()` throws for a null-prototype object. The handler itself then threw. In detection, a resource whose read failed, whose type has no READ handler, or whose dynamic reference could not be resolved aborted the stack instead of being reported and skipped; a failed IAM principal lookup failed the resource's comparison instead of leaving the principal as written; and an unreadable nested-stack ancestor rejected instead of making the producer-region evidence incomplete. `--accept` and `--revert` rejected after their work on a failed lock release. In `--revert`, a failed update, re-resolution or payload build abandoned the rest of the stack and its state write; a revert that LANDED was re-reported as `AWS update failed` when the provider's effective properties or returned attributes could not be read; and a failed best-effort state write after a landed revert rejected instead of warning. Each now goes through `describeAwsFailure(x).detail`, byte-identical for an `Error` and a placeholder otherwise. Tests: `tests/unit/cli/drift-string-outthrow-3361.test.ts`.

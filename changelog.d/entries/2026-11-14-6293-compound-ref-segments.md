- **`Ref` of `AWS::Logs::LogStream`, `AWS::Logs::SubscriptionFilter`, `AWS::SSM::MaintenanceWindowTarget`, `AWS::SSM::MaintenanceWindowTask` and `AWS::CodeDeploy::DeploymentGroup` returns the value CloudFormation returns, not cdkd's compound physical id (issue [#6293](https://github.com/go-to-k/cdkd/issues/6293))** -- `src/deployment/intrinsic-resolver/ref-values.ts`. These types are created through Cloud Control with a pipe-joined id (`<LogGroupName>|<LogStreamName>`, `<FilterName>|<LogGroupName>`, `<WindowId>|<WindowTargetId>`, `<WindowId>|<WindowTaskId>`, `<ApplicationName>|<DeploymentGroupName>`), so a `Ref` in an output or in another resource's property handed back the whole compound id where CloudFormation returns the stream name, filter name, target id, task id or group name. Tests: `tests/unit/deployment/intrinsic-functions.test.ts`, and the new `ref-shape-compound-cc-ids` integ fixture.

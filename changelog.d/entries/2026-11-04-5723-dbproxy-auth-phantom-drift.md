- **`cdkd drift` no longer reports phantom `Auth` drift on a freshly deployed `AWS::RDS::DBProxy` (issue [#5723](https://github.com/go-to-k/cdkd/issues/5723))** -- `src/provisioning/providers/rds-dbproxy-provider.ts` (`readCurrentState`). Each `Auth` element was built with every `UserAuthConfigInfo` member, so the members AWS does not report for a secrets-auth entry (`Description`, `UserName`) were present as `undefined`. The baseline is persisted as JSON, which drops them, and the comparator's array-element walk counts own keys, so a drift-clean proxy showed two identical `Auth` lines, `drift` exited 1, `--revert` issued a needless `ModifyDBProxy`, and `--accept` could not converge it. The readback now omits each member AWS does not report.

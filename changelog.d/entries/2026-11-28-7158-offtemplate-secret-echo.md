- **A secret that AWS echoes under a property the template does not set is now stored masked, and `cdkd drift` reports it as not compared (`maskedEcho`) instead of as drift; a custom resource attribute whose name holds a secret is no longer stored (issues [#7158](https://github.com/go-to-k/cdkd/issues/7158), [#7152](https://github.com/go-to-k/cdkd/issues/7152), [#7153](https://github.com/go-to-k/cdkd/issues/7153))** -- `src/deployment/secret-redaction/off-template-echo.ts`, `src/deployment/secret-redaction/secret-attribute-keys.ts`, `src/deployment/deploy-engine/state-persist.ts`, `src/cli/commands/drift/{compare,redaction,outcome}.ts`. Before this change, some secrets were stored in `state.json` in plaintext, in the readback copy (`observedProperties`) under a key the template does not set, wherever no needle covered the value:
  - a `NoEcho` value of 1 to 3 characters embedded in a longer value;
  - any `NoEcho` value on a resource the deploy left unchanged;
  - an `ssm-secure` / `secretsmanager` reference inside a list;
  - two references that resolve to the same value.

  Each writer of a readback now reads the value from the readback at the positions the record marks as secret and masks every leaf, under a key the template lacks, that contains it. This covers the deploy save (and so the journal and the rollback restore), `cdkd state refresh-observed`, `cdkd import`, `cdkd state scrub` and the rollback's baseline refresh. It records those positions in a new optional field, `observedMaskedLeaves`, with no schema version bump. Values that are not learned: a public `ssm` value, the region, the stack name, a value the physical id contains, and a value under 4 characters echoed whole. `cdkd drift` reports a mask-only difference at such a position as `notCompared: maskedEcho` (exit `0`, like `noEchoParameter`). `--accept` and `--revert` keep the position masked. An existing record holding such plaintext is masked on its next save. A custom resource attribute whose KEY contains a secret is dropped from the stored record, unless a template `Fn::GetAtt` spells that key. An older cdkd binary ignores the field, so its `cdkd drift` reports such a position as drift. Tests: `tests/unit/deployment/off-template-echo-7158.test.ts`, `tests/unit/cli/drift-masked-echo-7158.test.ts`.

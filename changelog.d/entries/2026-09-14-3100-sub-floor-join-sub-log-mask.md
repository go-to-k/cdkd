- **`--verbose` no longer prints a 1-3 character secret that an `Fn::Join` or `Fn::Sub` embeds in a longer string (issue [#3100](https://github.com/go-to-k/cdkd/issues/3100))** -- `src/deployment/intrinsic-function-resolver.ts`, with cases in `tests/unit/deployment/intrinsic-resolver-sub-floor-log-mask.test.ts` and `intrinsic-resolver-assembled-secret-region.test.ts`, and a `--verbose` arm in the `secrets-dynamic-ref` integ. The debug lines masked resolved strings with the recorded-secret needle mask, which matches a value under four characters only as the whole text, so `port:` + `secretValueFromJson('pin')` printed as `port:q7`. The resolver now builds a log twin of each value at the writes that put a recorded secret into it (the dynamic-reference substitution's fresh, cache-hit and region-pinned arms, reference-bearing parts and variables, intrinsic products masked whole or by a mask an earlier write of the pass registered, `Fn::Split` pieces) and prints the twin, masking the whole text when the needle mask also changes the value. It reaches the `Fn::Join` / `Fn::Sub` lines, the `Fn::Base64` line (whose encoding is masked whole when its input carries a mask), and every line and thrown message that prints a value through the resolver's leaf mask (`Fn::Select`, `Fn::Split`, `Fn::Cidr` and the other callers), and no other line. A literal Join part, Sub variable or Sub body equal to a recorded value is not masked, while a `Fn::Split` whose whole source is a recorded secret masks every piece. The resolved value and state are unchanged. Residuals: [#3113](https://github.com/go-to-k/cdkd/issues/3113) (another lane's fixture scan) and [#3114](https://github.com/go-to-k/cdkd/issues/3114) (a nested child `Ref` to an intrinsic-framed parameter, and a value resolved in two stages).

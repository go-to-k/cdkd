- **`cdkd diff` and the deployment events mask a secret-derived name a parent passes to a nested stack (issue [#3869](https://github.com/go-to-k/cdkd/issues/3869))** -- `src/cli/commands/diff-recursive.ts`, `src/deployment/deploy-engine.ts`. Consider a nested stack whose parameter reads a resource named from a secret, such as `Parameters: { QueueUrl: Ref SecretQueue }`. `cdkd diff --recursive` discarded the needles of that read, so its walk into the child printed the queue name on the child's `Parameter QueueUrl: using user-provided value` line, its `Ref` lines and its changed rows. The row's reads now go into a mask-only bag. That bag is bound around the child's whole walk and masks its rows, a grandchild's included. It never joins the child's inherited secrets, so no export preview moves. A deleted nested stack's stored values are masked too, with the needles of the live stack above it and of every record named from a secret. On deploy, a nested child engine's event text in `deployments/*.jsonl` was masked only with the child's own secrets. That text is an AWS error quoting such a value. Every event is now masked in one pass with the resource's own secrets and the printing bags bound where it is recorded. That masker, the log sink and every printed-text mask now mask overlapping needle matches as one span, so neither leaves a fragment; a rollback refusal still masks a needle spanning lines. `src/deployment/secret-redaction/log-only.ts`, `mask-errors.ts`, `src/deployment/secret-name-needles.ts`. The `physicalId` field is unchanged. Tests: `tests/unit/cli/diff-secret-name-needles-3869.test.ts`, `tests/unit/deployment/secret-name-needles-3869.test.ts`, `tests/unit/deployment/deploy-engine-derived-name-needle-3869.test.ts`. Integ `secret-derived-immutable-names` step 5b now runs `cdkd diff --recursive` and FAILs when the child's lines name the queue; it used to print a NOTE.

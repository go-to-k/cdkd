- **`cdkd diff` and the deployment events mask a secret-derived name a parent passes to a nested stack (issue [#3869](https://github.com/go-to-k/cdkd/issues/3869))** -- `src/cli/commands/diff-recursive.ts`, `src/deployment/deploy-engine.ts`. Consider a nested stack whose parameter reads a resource named from a secret, such as `Parameters: { QueueArn: GetAtt SecretQueue.Arn }`. `cdkd diff` discarded the needles of that read, so its walk into the child printed the name on the child's `Parameter QueueArn: using user-provided value` and `Resolved Ref to parameter: QueueArn` lines and in the child's changed rows. The row's reads now go into a mask-only bag that is bound around the child's whole walk and masks its rows, a grandchild's included. It never joins the child's inherited secrets, so no export preview moves. On deploy, a nested child engine's event text in `deployments/*.jsonl` (an AWS error quoting such a value) was masked only with the child's own secrets. Every event is now also masked with the printing bags bound where it is recorded, as its log lines are. The `physicalId` field is unchanged. Tests: `tests/unit/cli/diff-secret-name-needles-3869.test.ts`, `tests/unit/deployment/secret-name-needles-3869.test.ts`. Integ `secret-derived-immutable-names` step 5b now FAILs when the child's parameter lines name the queue; it used to print a NOTE.

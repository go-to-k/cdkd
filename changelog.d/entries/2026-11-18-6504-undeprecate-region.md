- **`--region` is a supported flag again on every command, and `cdkd import` accepts it (issue [#6504](https://github.com/go-to-k/cdkd/issues/6504))** -- `src/cli/options.ts`, `src/cli/region-options.ts`, `src/cli/commands/**`. cdkd deprecated `--region` outside `cdkd bootstrap` / `cdkd gc` before the AWS CDK CLI added its own stable global `--region` ("Use the indicated AWS region as the default region"). cdkd follows the CDK CLI, so the flag is no longer deprecated: `--help` lists it on every command that takes it, including the `cdkd local start-*` commands, and passing it no longer prints the "`--region is deprecated and will be removed in a future release`" warning. `cdkd import` now declares the flag too: it already read the value, but the missing declaration made `cdkd import --region <r>` fail with `unknown option '--region'` where `cdk import --region <r>` works. Precedence is unchanged: `--region`, `AWS_REGION`, `AWS_DEFAULT_REGION`, the profile's region, `us-east-1`, and a stack with `env.region` set keeps that region. The planned removal at v1 is cancelled.

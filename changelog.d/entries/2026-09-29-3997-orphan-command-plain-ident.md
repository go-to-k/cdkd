- **`cdkd export`'s `cdkd state orphan` remedy withholds a stack name or region that is not a plain identifier (issue [#3997](https://github.com/go-to-k/cdkd/issues/3997))** -- `src/cli/commands/export.ts`, with unit tests in `tests/unit/cli/export.test.ts` and `export-nested-failure-render.test.ts`. The remedy named any value that rendered exactly, shell-quoted, so a record name with a space or a shell metacharacter was printed on the labelled command line, where a terminal can wrap its padding into what reads as a second line. It now builds the command with the plain-identifier rule the `cdkd state` and `cdkd destroy` remedies use: such a value becomes a quoted hole like any other withheld value, and the note above the command says the value "is not a plain identifier (a letter or digit, then letters, digits and ~ _ . -), which cdkd does not print on a command line".
